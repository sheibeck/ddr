## Phase Goal

**As a** Mazeworld player, **I want to** install the game as a native Android app, **so that** I can play it from my phone's launcher instead of a browser tab.

*(Derived from the ROADMAP Phase 2 `**Goal:**` line under MVP_MODE. This plan delivers the first slice of that story: the web game compiles into an installable native Android APK — the platform skeleton every later slice builds on.)*

<objective>
Stand up the Capacitor 8 Android project around the existing zero-bundler web game and prove it compiles headlessly. This is the platform de-risking slice: install the exact pinned toolchain (Temurin 17 + android-36), install Capacitor + the five plugins, author the single-source-of-truth `www/` assembly script, generate the native `android/` project, and get a bare `assembleDebug` to exit 0.

Purpose: Surface JDK/Gradle/AGP/SDK problems now (the highest-risk unknown of the phase) with a real build, not later. Keep the game zero-runtime-dependency — Capacitor is build tooling and platform bridges only.

Output / artifacts this plan produces:
- `capacitor.config.json` (appId `com.darktierstudios.mazeworld`, appName `Mazeworld`, webDir `www`, local-only WebView).
- `tools/build-www.mjs` — the copy + vendor + import-map-inject build script.
- The generated `android/` project (committed as source), plus `android/gradle.properties` (JDK 17 pin) and `android/local.properties` (SDK dir, gitignored).
- `package.json` build scripts; `.gitignore` entries for `www/` and `android/local.properties`.

NOTE: A bare `assembleDebug` here does not yet include the branded splash/portrait lock/self-hosted fonts (that is 02-04) or the async-storage/lifecycle wiring (02-03). This plan proves the wrap COMPILES; 02-04 produces the final green build with native chrome and the AAB.
</objective>
