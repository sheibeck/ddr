<objective>
Build the reusable prototype-parity harness infrastructure (the golden-master half of ENG-05)
BEFORE any engine slice exists, so each later slice can drop in a fixture and immediately get a
regression signal. This plan freezes the pristine prototype as an immutable fixture, loads it
headless in a node:vm sandbox with hand-written DOM/localStorage/canvas stubs, makes its RNG
seedable (mulberry32) so it draws the same rolls as the engine, and provides the diff comparator
that strips the four cosmetic wall-clock fields.

Purpose: 01-RESEARCH.md's core recommendation — a golden-master harness that runs the SAME
seeded action script through both the unmodified prototype and the extracted engine and diffs
state after every action. Freezing a copy protects the reference from the browser-adapter edits
plan 01-07 makes to the live file.

Output: frozen prototype fixture, sandbox loader, seedable Math.random, diffState comparator,
fixture-format docs, and a smoke test. No engine comparison yet (no engine slices exist) — the
per-slice parity tests are authored in plans 01-05 through 01-10.
</objective>

## Phase Goal

**As a** Mazeworld maintainer, **I want to** replay any seeded action script through both the pristine prototype and the extracted engine and diff their state, **so that** every extraction slice is provably regression-free before it merges.
