<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage / save file → rehydrate | A player can edit their own save via devtools, or a save can be truncated/corrupted. Untrusted bytes must not crash the app or inject non-data into GameState. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-06a | Tampering | edited/corrupt localStorage save | low | mitigate | validateSave parses defensively and fail-closes to newRun on broken JSON or missing c/floor; never throws mid-load (V12). Only affects the tamperer's own single-player run. |
| T-01-06b | Tampering | non-serializable data in RunSummary/items | low | mitigate | Item/RunSummary descriptors are plain data; a JSON round-trip test + applyAction's structuredClone catch any function leak, protecting ENG-04. |
| T-01-06c | Information | wall-clock timestamps leaking into determinism | low | mitigate | deathAt/when funnel through an injectable now(); stripVolatileFields excludes them from all parity/round-trip diffs. |

No package installs (T-01-SC N/A). No network/auth/session surface (offline single-player).
</threat_model>
