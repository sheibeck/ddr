<objective>
Make descent endless and fair: rewire `genFloor` to consume the bounded `difficultyCurve`
(from Plan 01) and always emit an "exit" descent tile (never "gate"); route any legacy
"gate" tile through `descend()`; retire `winGame()` as a run terminator; and add the
fairness / endless / high-depth-regression tests plus the deliberate retirement of the
now-obsolete Gate-win parity coverage. This is the phase's core behavior change — the ONE
intentional divergence from the frozen prototype (descent no longer ends at floor 5).
(RUN-02, RUN-03, RUN-04; honors CONTEXT locked decisions: permadeath is the ONLY terminator,
attrition-not-inflation, bound both darkness knobs independently, preserve determinism.)

Purpose: replace the fixed 5-floor Gate with a tuned endless descent while keeping every
unchanged behavior byte-identical to the prototype.
Output: bounded engine/maze.js + endless engine/movement.js, fairness + endless + regression
tests, and a documented retirement of the Gate-win parity fixture.
</objective>
