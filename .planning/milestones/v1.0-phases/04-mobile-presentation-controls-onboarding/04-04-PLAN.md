<objective>
Complete `formatEvents()` narration coverage of the engine's full event
vocabulary — the single largest hidden-scope item in this phase (04-RESEARCH.md
§7): the engine emits ~140 distinct event types across
combat/magic/economy/encounters/items/movement, but the temporary adapter
narrates only ~26. Until combat/economy are engine-routed (04-07), the gap is
invisible; the moment they are, dozens of resolved actions would produce ZERO log
line — a silent bug, not a missing string (Pitfall 4). This plan closes that gap
as a data-driven lookup table plus a standing coverage guardrail test.

Purpose: Make the Oracle/combat log (UX-05) fully driven by applyAction events,
and hand Phase 5's voice generator a clean, enumerable table to replace.
Output: `src/browser/eventNarration.js`, refactored `formatEvents`, coverage test.
</objective>
