Engine facts for the Method section: a day ticks every 100 squares walked or on a camp (engine/movement.js newDay via crossings(100) and makeCamp). descend() is reached only from resolveFeature on an "exit" (or legacy "gate") tile. Each store sells one Rations line once per visit. Beasts and Lair Beasts kills can yield a ration (always with Cooking, otherwise on a d6 roll of 4 or more). A fed night refills spell books and heals; an unfed night burns upkeep hp and can kill (cause "starve").
</interfaces>

The verdict rule (82-CONTEXT.md, locked, quoted for the ledger):
- Farming wins when the stronger farmer's p90 DAYS is at least the honest runs' p99 DAYS, or when any farmer run hits the cap.
- If floor-1 farming wins, DAYS ranks only runs that got past floor 1 (floor >= 2); DEPTH, KILLS and WILMST still list floor-1 deaths.
- If floor-2 farming wins too, the rule switches to a per-floor cap: DAYS rank key = min(days, 10 x floor), and the displayed value stays the true days.
- If farming does not win, DAYS ranks as the mock says (days desc, then floor desc), and nothing else changes.
</context>
