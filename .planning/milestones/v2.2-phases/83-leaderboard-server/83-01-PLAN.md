Lay the shared foundation every later Phase 83 plan builds on: one Firebase config module (reused by bug reports), one Firestore REST helper module (the moved typed-value encoder, a decoder, URL builders and a never-throwing timed fetch), and the rolled @handle (content word tables plus a pure roll/validate module with a by-construction safety proof).
