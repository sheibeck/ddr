<objective>
Build the anonymous player identity: a pure, DOM-free module that lazily signs up an anonymous Firebase user over plain REST, keeps uid and tokens in durable storage under `ddr.identity.v1`, refreshes the id token ahead of expiry, owns the rolled @handle (roll, re-roll), and makes zero network calls while Compete is OFF.

Purpose: SRV-04 (anonymous identity through REST with plain fetch, durable storage, token refresh, never created or refreshed with Compete OFF by the board), the identity half of SRV-05 (the handle is rolled locally, re-rollable), and the identity half of SRV-09 (a bug report needs the same shared identity, created on the player's first Send even with Compete OFF; todo 2026-09-28 requirement 1). SRV-09 is the later user decision, so the one exception to SRV-04's Compete gate is an explicit, player-tapped action; the board paths never pass explicit. Implements CONTEXT "Identity & the @handle": created lazily on the first Compete-ON submission; board reads need no auth; uid + refresh token (+ cached id token/expiry) under `ddr.identity.v1`, separate from settings, through the injected storage (the shell passes src/browser/storage.js in Phase 85); the handle is rolled with shell-side randomness the first time it is needed; erasing drops `ddr.identity.v1`.

Output: `src/browser/firebaseAuth.js` and `test/unit/firebaseAuth.test.js`.
</objective>

REST contracts used here:
- Sign-up: POST IDENTITY_BASE + "/accounts:signUp?key=" + encoded apiKey, JSON body {"returnSecureToken": true}; 200 body {idToken, refreshToken, expiresIn (seconds, string), localId}; a disabled provider answers 400 with error.message OPERATION_NOT_ALLOWED.
- Refresh: POST SECURETOKEN_BASE + "/token?key=" + encoded apiKey, Content-Type application/x-www-form-urlencoded, body grant_type=refresh_token and refresh_token=<token>; 200 body is snake_case {id_token, refresh_token, expires_in, user_id}.
- Delete: POST IDENTITY_BASE + "/accounts:delete?key=" + encoded apiKey, JSON body {"idToken": ...}; 200 on success.
</context>
