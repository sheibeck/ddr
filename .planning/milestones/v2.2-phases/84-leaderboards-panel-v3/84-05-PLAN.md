<interfaces>
Input to leaderboardView(input) (every field optional; bad values fall back):
- mode "board" | "mine" (anything else is "mine"; compete not true forces "mine")
- compete boolean; entry "tab" | "title"; hasHero boolean; dead boolean
- stat "deep" | "days" | "kills" | "purse" (else "deep"); race a content/races.js key or null; sub a content/classes.js sub or null (unknown ids read as null)
- open a row key or null; sheet null | "stat" | "race" | "sub"
- history: an array of history records (84-03 shape: hash, name, race, cls, sub, level, floor, day, steps, kills, gold, sp, cause, note, epitaph, when, version, season), newest first
- board: null | {status:"loading"} | a BoardSnapshot (84-04: status, reason, stale, fetchedAt, rows, total, filteredTotal, you {id, rank, listed, run} | null, youKnown, uid); rows are decoded run docs (uid, handle, name, race, sub, cls, level, floor, day, steps, kills, gold, sp, cause, note?, epitaph, when?, version, createdAt ISO string, id)
- now number (ms); tzOffsetMinutes number (Date#getTimezoneOffset, default 0); season integer (default content/season.js SEASON)

Output view (plain data, no functions):
- mode, entry (the normalised "tab" | "title"), stat, col (the stat's colour)
- header {title, scopeLine, seasonLine ("" on mine), back boolean, backLabel, box {n string, label, action "mine" | "board" | null}}
- pickers: [{id:"stat", label, value, col, active:true}, {id:"race", label, value, active}, {id:"sub", label, value, active}]
- body: {kind:"rows", rows} | {kind:"empty", title, note, clear: {id:"clearFilters", label} | null} | {kind:"note", line, action: {id:"seeMine", label} | null}
- staleLine string ("" unless the board snapshot is stale)
- standing {note, place} | null
- sheet null | {id, title, done, opts: [{value (null for ANY), label, sub, n (string, "" when uncounted), dim, on, col ("" off the stat sheet)}]}
- dock null | [{id, label, primary}]
- row: {key, rank, top, podium, you, divider, headline, tag, line, val, unit, open, detail, stats [{k, v}] x6, dateLine, avatar {initials, bg, on}}

Helpers to port from src/browser/boardsView.js unchanged: AVATAR_PALETTE, avatarColour(key), initialsOf(key), ordinal(n) (account.js will import avatarColour/initialsOf from this module once 84-09 retires boardsView.js).
</interfaces>
