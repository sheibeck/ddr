<interfaces>
boardClient (Phase 83): createBoardClient({fetchFn, config, competeOn, now, ttlMs, season, ...}) -> {topTen(stat, race?, sub?) -> {ok:true, rows, stale, fetchedAt} | {ok:false, reason}, total(stat, race?, sub?) -> {ok:true, count, stale, fetchedAt}, rankOf(stat, key, race?, sub?) -> {ok:true, rank, ahead, stale, fetchedAt}, clear()}. Gate order: competeOn -> config/fetchFn -> argument validation -> cache -> in-flight -> network. Reasons: off, offline, server, refused, invalid, unavailable. Rows are decodeRunDocument(doc): the doc fields plus `id`; createdAt decodes to an ISO string.

runDoc (84-01): ownRunsQuery({uid, limit = 50, afterName}) orders by __name__ ascending and pages with startAt {referenceValue: afterName, before: false}; LIST_LIMIT_MAX = 50; rankKeyOf(stat, run); RUN_COLLECTION.

fakeBoardServer (Phase 83): createFakeBoardFetch({config, now, online, runs}) -> {fetchFn, calls, setOnline, ...}; `runs` seeds {id, doc} without validation (so older-shape docs can be seeded).

firebaseAuth (Phase 83): identity.snapshot() -> Promise<{handle, uid}> reads local storage only (no network, never creates an identity).

BoardSnapshot (the shape this plan defines; 84-05's view consumes it; all frozen):
- status: "ready" | "unreachable" | "off"
- reason: null or the topTen failure reason
- stale: boolean; fetchedAt: number or null (the oldest fetchedAt of the reads that fed it)
- rows: the top-ten decoded docs in server order ([] unless ready)
- total: the unfiltered current-season count, or null; filteredTotal: the count under race/sub (equal to total when both are null), or null
- you: null or {id, rank, listed, run}; youKnown: false when the own-runs read (or the needed rankOf) failed; uid: the snapshot uid or null
</interfaces>
