<record_spec>
The record (the value stored under `ddr.achievements.v1`; Claude's Discretion in CONTEXT, fixed here because Phases 100 and 101 read it). Every key is present after `sanitizeRecord`, and every record either module returns is deep-frozen (Object.freeze, recursively), so a caller can never mutate it.
- `v`: 1.
- `counters`: `{ deaths, joinersAccepted, joinersFallen, parleysWon, trapsSurvived }`.
- `kills`: one key per BESTIARY key, in BESTIARY order (`Beasts`, `Demons`, `Humans`, `Lair Beasts`, `Magical`, `Walking Dead`).
- `bests`: `{ depth, days, wilmstHeld, fleesWon, depthByRace, depthByClass }`; `depthByRace` has one key per RACES key, `depthByClass` one per CLASSES key.
- `flags`: `{ diseaseLeftOnOneHp, poisonLeftOnOneHp }`, booleans.
- `subClassesDelved`: array of distinct sub-class names drawn from CLASSES[*].subs, first-seen order.
- `unlocked`: plain object mapping a catalog id to its unlock time in integer epoch milliseconds.
- `revealed`: array of distinct ids of catalog entries whose initialState is Hidden, in reveal order.
- `run`: null, or `{ tag, seen, stepped, naked, teetotal, fleesWon }`: `tag` a non-empty string, four booleans, `fleesWon` an integer. This is the current-run progress, tagged to its run (CONTEXT D 'Contents').
Numeric rule: a finite number at least 0 is floored and capped at Number.MAX_SAFE_INTEGER; anything else becomes 0.

sanitizeRecord(raw): a non-plain-object or a `v` other than 1 returns `emptyRecord()` (older shapes load as zeros; no migration). Otherwise field by field: numbers by the numeric rule; flags true only when exactly `true`; unknown keys dropped and missing keys filled; `subClassesDelved` keeps real sub-class strings, deduped; `unlocked` keeps catalog ids only, and a catalog id with an invalid time keeps its unlock at time 0 (an unlock is never dropped for a bad date); `revealed` keeps Hidden catalog ids, deduped, then appends any unlocked Hidden id it is missing; `run` is kept only when it is a plain object with a non-empty string `tag` (booleans by `=== true`, `fleesWon` by the numeric rule), else null.
parseRecord(text): a non-string, an empty string or a JSON.parse failure returns `emptyRecord()`; otherwise `sanitizeRecord(JSON.parse(text))`. serializeRecord(record): `JSON.stringify(record)`.
</record_spec>

<tracker_spec>
The fold (CONTEXT D 'Tracker and hooks'; the evaluation of each TRIGGER_VOCABULARY kind is Claude's Discretion, fixed here).

State fields read, and nothing else (document this list in the module header): `dev`, `seed`, `day`, `steps`, `floor.depth`, `c.name`, `c.race`, `c.cls`, `c.sub`, `c.gold`, `c.weapon`, `c.armor`, `c.worn.jewelry1`, `c.worn.jewelry2`, `c.worn.cloak`. A missing or malformed field reads as 0 or empty and never throws.

runTagOf(state): the string seed, race, sub and name joined with `|` (GameState holds no start time; a real run's seed is the wall-clock moment of its roll, so this identifies the run).

filledSlotCount(c): how many of the five worn slots are filled: weapon is a non-empty string other than "Fists"; armor is a non-empty string other than "Nothing" (the literal ruling: a destroyed piece still in the slot counts as filled until UNEQUIP clears it); `worn.jewelry1`, `worn.jewelry2` and `worn.cloak` are truthy. Bag items and the torch are never read.

options: `{ now, catalog }`. `now` is the unlock date (a finite number at least 0, floored; otherwise 0). `catalog` defaults to ACHIEVEMENTS and is always evaluated sorted by listOrder, ties by id.

Result of both entry points: `{ record, unlocks, reveals, progress, changed }`, deep-frozen. `unlocks` is `[{ id, at }]`, `reveals` is `[id]`, `progress` is `[{ id, value, steps }]`, each in list order. When nothing changed, `record` is the very object passed in and `changed` is false.

beginRun(record, state, options): a null record is `emptyRecord()`. A missing state or `state.dev === true` returns the unchanged result. Otherwise the run section becomes `{ tag: runTagOf(state), seen: true, stepped: false, naked: true, teetotal: true, fleesWon: 0 }` (resets Chicken, Naked and Teetotaler for the new run), the state's sub-class is appended to `subClassesDelved` when it is a real sub-class not already there, and the shared evaluation below runs with `after` = state and no death.

foldAction(record, events, before, after, options):
1. Guards: a null record is `emptyRecord()`; a missing `after`, `after.dev === true` or `before.dev === true` returns the unchanged result; a non-array `events` is empty.
2. Run section: when `record.run` is null or its tag differs from `runTagOf(after)`, the run is one the tracker did not see start (a pre-2.5 save resumed): `{ tag, seen: false, stepped: true, naked: false, teetotal: false, fleesWon: 0 }`.
3. Events, in order: `foeKilled` with a BESTIARY-key `group` adds 1 to that kill count (any other group is ignored); `walkingDeadTurned` adds its `count` (a non-negative integer) to Walking Dead; `joinerJoined` adds 1 to joinersAccepted; `memberDowned` and `joinerMurdered` each add 1 to joinersFallen; `parleyWon` adds 1 to parleysWon; `trapSprung` adds 1 to a local sprung count; `fled` with reason `escaped` adds 1 to run.fleesWon (door, cloaker, tracked, smoke do not); `potionDrunk` sets run.teetotal false (no other event touches it, memberPotionDrunk included); `afflictionCaught` with `first` above 0, or `afflictionTick`, whose `wp` is exactly 1 sets the Disease or Poison lifetime flag by its `kind`; the first `died` sets the action's death cause and, when that cause is not `abandon`, adds 1 to deaths; `moved` marks that a step happened.
4. trapsSurvived adds the sprung count minus one when the death cause is `trap`, never below 0.
5. First step: when the run is seen and not yet stepped, and the action had a `moved` event or `after.steps` exceeds `before.steps`, set stepped true and naked to whether `filledSlotCount` of the state the step was taken from (`before.c`, falling back to `after.c`) is 0.
6. Naked break: when stepped and naked and `filledSlotCount(after.c)` is above 0, naked becomes false.
7. Bests: depth, days, wilmstHeld (`c.gold`) and fleesWon (run.fleesWon) each keep their maximum; `depthByRace[c.race]` and `depthByClass[c.cls]` keep their maximum depth when the key exists.
8. Shared evaluation: every catalog entry not already in `unlocked` is met when:
   - lifetimeCounter: the counter (kills by `group`, else `counters[counter]`) is at least the threshold;
   - singleRunBest: the metric's best (depth filtered by `race` through depthByRace or by `parentClass` through depthByClass, else bests.depth; days; wilmstHeld; fleesWon) is at least the threshold;
   - singleRunFlag fullyDressed: `filledSlotCount(after.c)` is 5 (null threshold: the moment it holds);
   - singleRunFlag nakedAtFirstStep: the run is seen, stepped and naked, and `after.floor.depth` is at least the threshold (the judged floor);
   - singleRunFlag noHealingPotion: the run is seen and teetotal, and `after.floor.depth` is at least the threshold;
   - deathCause: the action's death cause exists and is not `abandon`, `causes` is null or includes it, and `floor` is null or equals `after.floor.depth`;
   - lifetimeFlagPair: every listed flag is true;
   - distinctSetCount: the named set's length is at least the threshold;
   - an unknown kind, metric or flag is never met.
   Met entries are written to `unlocked` with `at` = now and returned in list order.
9. Reveals: for each new unlock in list order, its own id when it is Hidden, then each id in its `reveals` whose entry is Hidden; drop ids already revealed, dedupe, sort by listOrder, append to `revealed`, return them.
10. Progress: for each incremental entry not unlocked in the input record, compare `min(measure, steps)` in the input record and the output record; when it changed, report `{ id, value, steps }`. measure is the counter for lifetimeCounter, the metric best for singleRunBest, the set length for distinctSetCount. `progressFor(record, entry)` returns `{ value: min(measure, steps), steps }` for an incremental entry and null for a standard one.
11. changed is true when the output record differs from the input (compare their serialized forms); then return the new deep-frozen record, else the input object.
Imports allowed: `../../content/achievements.js`, `../../content/bestiary.js`, `../../content/races.js`, `../../content/classes.js` and `./achievementRecord.js`. No engine import, no storage, no DOM, no clock, no random source.
