<bus_spec>
src/browser/achievementBus.js has no imports. Exports:
- `createAchievementBus()` returns a frozen object `{ subscribe, publish, size }`, all closures (no `this`).
  - `subscribe(fn)`: a function is added to an insertion-ordered set (the same function twice is one registration) and an unsubscribe function is returned (calling it twice is harmless). Anything that is not a function registers nothing and returns a no-op unsubscribe.
  - `publish(payload)`: takes a snapshot of the subscribers and calls each in order inside its own try/catch with the payload untouched; a returned thenable gets a swallowing catch attached. Never throws, returns undefined (so the adapter's own thenable check finds nothing to attach).
  - `size()`: the number of registered subscribers.
- `achievementEvents`: the one shared instance, created at module load.
The header comment states the contract for Phase 101: subscribe to `achievementEvents`; never call `setAchievementListener` yourself; the shell owns that single slot and hands it `achievementEvents.publish`.
</bus_spec>

A null or malformed queue reads as the empty queue; a non-array `unlocks` adds nothing.
- `bannerNext(queue, ctx)`: returns frozen `{ queue, card, strip }`. ctx fields are booleans: `ready` (a hero is loaded and the dungeon is visible), `fighting`, `dead`, `fade`, `decision`, `railBusy`.   3. more than ACHIEVEMENT_COLLAPSE_OVER pending: card = `achievementSummaryCard(pending)`, queue empty.
  4. otherwise: card = `achievementCardFor(pending[0])`, queue = the rest.
- `earnedStripView(ids)`: null for no resolvable id; else frozen `{ label: ACHIEVEMENT_CARD_COPY.strip.label, items: [{ id, name, iconSrc }] }` in list order.
