<objective>
Make the worn model REACHABLE for real players without moving a single fixture byte: (1) `newRun(seed, exclude, { wornSlots: true })` — an option ONLY the shell's new-game path sets (the `storeRoll` precedent) — creates `c.worn` via `reconcileWorn(c)` so a fresh Thief wears their starting cloak; (2) the load-time migration in `engine/saveState.js` (`validateSave` / `rehydrate`, beside `migrateCarry`/`clearFoeEffect`/`clearStaleTimers`): for any save whose `c` lacks `worn` it creates the map, wears the FIRST item of each slot type in bag order, leaves every later copy in the bag (never overflowing — moving bag->worn only frees slots), never re-migrates a save that already has `worn`, and RETURNS a reconciliation report `[{ slot, worn, bagged }]` on `validateSave`'s result instead of writing any serialized field; a present-but-tampered `worn` is neutralised on every load like `clearStaleTimers`; (3) `src/browser/engineAdapter.js` passes the option from `boot()` and `startNewRun()` and exposes `takeBootWornReport()` (returns once, then null) for Plan 04's rail card; (4) `src/browser/rail.js` owns the reconciliation copy (`RAIL_COPY.wornReconciled`, voice-scanned by rail.test.js) and a pure `wornReconcileCard(report)` builder; (5) `src/browser/combatMenu.js` lists worn activatables in the combat ITEMS submenu with the `useItem { slot }` dispatch — otherwise a worn staff could not be used in a fight.

Per CONTEXT §"Old-Save Reconciliation & Parity" (locked): migration on load in saveState.js for any save lacking `worn` — first copy worn, extras bagged, never overflowing, never re-migrated; fresh runs via the shell-only `wornSlots` option (Thief cloak worn; fixtures/bots/every existing `newRun(seed)` caller byte-identical); the migration returns a report `[{ slot, worn: name, bagged: [names] }]`; the shell surfaces it once (Plan 04) only when at least one extra was bagged. Surfaced assumption (frontmatter): the migration is gated on the same option so the six standing rehydrate round-trip contracts stay untouched; `boot()` always passes it, so every real load migrates.

Purpose: ROADMAP SC-3 (an old save with two of one slot type loads without a crash and the extra is narrated into the bag — engine + adapter half; the rail line is Plan 04) and the new-run half of SC-1/SC-2.
Output: state.js option, saveState.js migration + tolerance + report, engineAdapter plumbing, rail copy/builder, combatMenu worn rows, `test/unit/worn-migration.test.js`, targeted additions to three existing test files.
</objective>
