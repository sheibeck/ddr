## Flagged assumptions

- **The draft lives in the module script's memory** (`reportModel`), per D-09 ("in memory is enough"). It never goes to storage, so it can't outlive the app process.
- **Close is refused while sending.** The back button or scrim during the at most 15 s send does nothing visible. The press is consumed, which matches "the controls locked" (D-09).
- **The ledger covers the phase's copy.** It covers every UI line new in 79.3, including 79.3-03's `PATCH_NOTES_COPY` and 79.3-04's labels. 79.3-07 adds no copy, so this is the phase's one ledger file.

- **The keydown guard is in the classic script** (the listener lives there), and checks the sheet's `hidden` flag through the DOM. The classic script can't see module-scope functions.
  - The guard's comment must avoid the word "movement": shell-arrow-pad.test.js (e) pins its absence in the keydown region.
