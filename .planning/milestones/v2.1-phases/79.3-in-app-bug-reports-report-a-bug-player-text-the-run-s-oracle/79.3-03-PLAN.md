## Flagged assumptions (surfaced for the orchestrator)

- **versionName moves to 2.1.0 now; versionCode does not.**
  - D-19 fails the build when the current versionName has no notes file. D-18 names the file `2.1.0.md`.
  - Leaving `versionName=2.0.0` would break `npm run build:www` in this very phase (and in 80-04), unless a retroactive `2.0.0.md` were written.
  - The code on master is the 2.1 line, and `play:release` bumps versionCode at the push. So this plan sets `versionName=2.1.0` and leaves `versionCode=10`.
  - The alternative, keeping 2.0.0 and writing a `2.0.0.md`, is the orchestrator's to choose instead. If chosen, swap step 5 of Task 2 for that file.
- **D-21 confirmed, with one refinement.**
  - A fresh install marks the version seen without showing the notes.
  - An install with no seen-version key but prior app data (a save, graveyard, bests or settings key) is an upgrade from a build that predates the notes, such as 2.0.0 → 2.1.0, so it shows once.
  - Without this refinement, every 2.0 player updating to 2.1 would never see the 2.1 notes.
- **The auto-show key is the versionName.** A versionCode-only internal-testing push, with the same notes, never re-pops the sheet.
- **The Play cut is the Headline section.** Its paragraph plus its bullets, with the author choosing the top bullets. `--play` and `--check` exit 1 when it is over 500 characters (D-22 "errors if the cut exceeds 500").
- **Why the data module is generated and committed.** D-19 says the dev loop reads the same file. The browser can't import `.md`, and the shell has no network call. So `tools/patch-notes.mjs --write-module` generates `src/browser/patchNotesData.js`. The build regenerates it in www from the Markdown, and a test pins the committed copy to the Markdown.
- **The notes body is release content, not ledgered copy** (the addendum's Copy note). `patchNotesData.js#PATCH_NOTES` is registered as non-copy in the voice corpus.
  - Because the module lives in src/, `tools/stale-terms.mjs` scans it.
  - The README warns authors off the enforced retired terms, for example the retired name for rail lines, the D-pad, and "classic engine".
- **The validator lives in tools/, not src/browser.** Its error sentences would otherwise enter the voice corpus's raw sweep. The same goes for NOTES_CATEGORIES ("Abilities & spells" reads as copy).
