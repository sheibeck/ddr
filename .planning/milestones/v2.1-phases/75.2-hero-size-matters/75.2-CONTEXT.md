# Phase 75.2: Hero Size Matters - Context

**Gathered:** 2026-09-25 (user answers during the Phase 73 run)
**Status:** Ready for planning

<domain>
## Phase Boundary

Make a hero's SIZE a real stat (RULES-11). Race sets it, items step it, and it changes damage, how easily foes hit you, and every size-based rule. The Gauntlet of the Giant and Enlarge then deliver what their text says.

**Today** (scouted 2026-09-25):
- The hero's size is read in exactly one place: +2 flat damage per `eff(c,"size")` step (engine/derived.js ~L1051 and ~L1371).
- `content/races.js` already carries `size` (Human, Small or Large) per race, but the engine never reads it.
- Enlarge gives +4 damage through a separate "might" record and never touches size.
- Foe size (bestiary `sz` T/S/M/L/H) already drives rules: small foes "strike as one level lower", the Knight vs big-foe initiative rule, and others.

**Not in scope:**
- Low-ceiling or tight-passage map tiles. That would be a new map feature; drop the "mind the ceilings" promise instead.
- The foe Shrink spell (already mechanical).
</domain>

<decisions>
## Implementation Decisions (user, 2026-09-25)
- **Base size comes from race**, using the existing `content/races.js` data: Elven and Dwarven are Small, Troll is Large, and Human, Wilmsry and Fridgian are Human-size.
  - Size is a step scale (Small −1, Human 0, Large +1, extended as items stack), where the total = race base + `eff(c,"size")`.
- **What a step does** (the user picked the fullest option):
  - Each step UP: +2 damage (today's rule, now also from race), and foes hit the hero ONE FACE MORE EASILY (one extra winning face for the foe).
  - Each step DOWN: −2 damage (floored so damage never goes below the existing minimums), and foes need ONE FACE MORE.
  - The modifier is signed for the roller in `mods` ({name:"size", delta}), so Phase 74's formatter shows it from the player's view.
  - **Rules that care about a creature being big or small read the hero's size too**, not only the foe's. The planner enumerates every such rule in engine/ and content/ and applies the hero's size symmetrically where the rule's text implies it: the Knight big-foe initiative, small-foe "strike as one level lower", size-based to-hit or damage notes, and so on. Each one is recorded in a table in the plan.
- **Items:** the Gauntlet of the Giant and the Enlarge potion are EACH exactly a +1 size step for their duration.
  - Enlarge's separate +4 damage ("might") is REMOVED.
  - Their text states exactly what a step does, e.g. "one size larger for fifty squares: +2 damage, easier to hit". The "mind the ceilings" promise is dropped.
  - Any other size-changing item or potion follows the same rule.
- **Display:** the hero sheet shows the size (e.g. "SIZE Small"). The foe-hit roll breakdown includes the size modifier. Condition chips show a stepped size while it lasts.
- **Engine gate (standing):**
  - Race size now affects every Elven, Dwarven and Troll run, so chargen, combat and movement fixtures for those races WILL move. Measure the moved set with `tools/fixture-inventory.mjs`, declare each in `test/parity/FIXTURE-INVENTORY.md`, and regenerate ONLY those. Never edit the prototype master.
  - No new rng draws (size is a pure read).
  - Carve new serialized fields out of the comparables.
  - Take a bot readout (`node tools/tune-difficulty.mjs --seeds=200`) before and after, and record both in `docs/DIFFICULTY-RETUNE.md`. This is a deliberate balance shift: Small races lose 2 damage but are harder to hit, and Trolls gain 2 damage but are easier to hit. Report the per-race effect, and don't compensate unless the user asks.
  - Written roll-high on Phase 73's helper; Phase 74's formatter handles any printed modifier.

<code_context>
### Race signatures and Joiners (user, 2026-09-25, after planning)
- **Race signatures survive size.** When a race's BASE size step and one of that race's own defining traits push the SAME stat in OPPOSITE directions, the race trait wins, and that axis of the base size step is dropped for that race. The size step then only adds; it never cancels a race's defining trait. Net effect:
  - **Dwarven:** Small's −2 damage is dropped because it conflicts with the Dwarven +2 damage, while Small's harder-to-hit face still applies. Net: +2 damage, and foes need one face more.
  - **Elven:** Small's harder-to-hit face is dropped because it conflicts with the thin-boned Phase 31 ruling, while Small's −2 damage still applies. Net: −2 damage, and still thin-boned.
  - **Troll:** Large points the same way as the Troll traits, so both axes stack (+11 damage, one face easier to hit).
  - **ITEM steps always apply in full on both axes** (the Gauntlet of the Giant, Enlarge, and future size items), on top of the resolved race base.
- **Joiners get size too:** one rule for every character. Each Joiner uses its own race's base size, with the same signature rule, for both damage and being hit.
