<interfaces>
- `isOwnRecord(score, mine, meId)`: true when either rule holds, else false. Never throws.
  - When `mine` is an object: if `str(score.playerId)` and `str(mine.playerId)` are both non-empty, the answer is whether they are equal. Otherwise the answer is whether `rankOf(score.rank) !== null`, `rankOf(score.rank) === rankOf(mine.rank)`, `score.rawScore === mine.rawScore` and `str(score.tag) === str(mine.tag)` all hold.
  - When `mine` is not an object: `str(score.playerId) !== "" && score.playerId === str(meId)`.
- `toGlobalEntry(score, index, { meId = "", mine = null, scope = "all" } = {})`:
  - `you = isOwnRecord(score, mine, meId)`;
  - `friend = scope === "friends" ? !you : s.friend === true`;
  - the rest unchanged.
- `load()`:
  - calls `provider.loadTopScores({ leaderboardId, collection, maxResults: TOP_N, forceReload: true })` and `loadPlayerScore` as today;
  - `mine` is the normalized own score or null;
  - maps the entries with `{ meId: meId(), mine, scope }`, then clears `you` on every entry after the first YOU (a new frozen object with `you: false`, and in FRIENDS `friend: true`);
  - `you` = the own record entry keyed `g:you` as today.
- `invalidate()`:
  - for every cache entry, sets a due marker so the next `view()` starts a fetch, while still returning the cached snapshot now (it stays readable while refreshing);
  - never starts a fetch itself and never calls the provider;
  - does not bypass an active retry backoff (`retryAt`);
  - an entry already in flight when `invalidate()` runs is refetched on the first `view()` after it settles.
- `playGames.loadTopScores`: forwards `forceReload: opts.forceReload === true` to the plugin (today it is hard-coded false). The fake provider accepts and ignores it.
- `boardsView` global rows: pin `snap.you` under the divider only when all of:
  - `rows.length > 0`;
  - no listed entry has `you === true`;
  - `rankOf(snap.you.rank) !== null`;
  - that rank is greater than the largest integer rank among the listed entries, or than `entries.length` when none has a rank.
- `buildGlobalStanding`: when `snap.you` exists, is not listed and has no integer rank, it returns `{ label: who + sep + unit, place: noPlace, note: G.hiddenYou }`.
- `createBoardsPanel({ ..., onOpen = null })`: `openFromTab()` and `openFromTitle()` call `onOpen()` inside try/catch before their render.
