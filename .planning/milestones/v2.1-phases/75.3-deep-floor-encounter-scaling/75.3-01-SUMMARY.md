## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `test/unit/roll-high-guard.test.js`'s shapes rule flagged `if (firstRoll <= 2) {` as an untagged roll-under comparison**
- **Found during:** Task 1 (full `npm test` run)
- **Issue:** The guard's S1 shape regex matches any `\w*Roll\b\s*<=` comparison unless the line carries a `// roll:selection` tag (the established convention for a table-pick dispatch ladder that looks like a magnitude check but isn't one). The plan's own instruction to "keep the roll:selection tag comment on the call site, not here" was about not duplicating the REAL draw's tag (which lives in `engine/combat.js` on the `rng.d(4)` line) — it didn't anticipate this separate build-failing guard, which requires every such comparison LINE to carry the tag regardless of whether a draw happens on it.
- **Fix:** Added `// roll:selection — a table pick on an already-drawn face, not a magnitude check` to the `if (firstRoll <= 2) {` line in `engine/difficulty.js`. Zero effect on `DRAW_INVENTORY` counts (a selection-tagged line with no `.d(` on it contributes 0, per that file's own documented convention).
- **Files modified:** `engine/difficulty.js`
- **Verification:** `node --test test/unit/roll-high-guard.test.js` (11/11 pass); full `npm test` (6516/6516).
- **Committed in:** `2d42128e` (Task 1 commit)

**2. [Deviation, no code change needed] `test/unit/combat-scaling.test.js`'s depth-20 wiring case did NOT need re-declaring, contrary to the plan's own prediction**
- **Found during:** Task 2 (full `npm test` run)
- **Issue:** The plan's interfaces block predicted this file's depth-20 wiring test (`fakeRng([3, 3, 2, 2])`, expecting 2 foes) would need updating to 3 foes, since RULES-16 raises depth-20 counts to a floor of 3. - **Resolution:** No edit to `test/unit/combat-scaling.test.js` — the full suite passed with it unmodified. Documented here per the plan's own instruction ("List every touched file in the SUMMARY; a failure that is not the count rule is a STOP") — this is the inverse case (a predicted-but-unneeded change), noted for the record rather than silently left unexplained.
