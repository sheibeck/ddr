  - `OUTCOME`: an object keyed by event type. Each value is a function `(event, following)` returning whether the ROLLER succeeded, where `following` is the rest of the same action's events (for pre-outcome events such as spellThrown or fleeRolled, whose outcome is a later event in the same action). Empty in this plan.

  - I5: every `mods` array holds `{ name: string, delta: non-zero integer }` entries.
  - I6 (only when COMPLETE): every event carrying `roll` also carries `atLeast`, or its type is in SELECTION_ROLL_EVENTS; and no event carrying `roll` carries `need`.
