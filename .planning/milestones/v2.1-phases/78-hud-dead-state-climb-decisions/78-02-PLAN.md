## Flagged assumptions (surfaced, not silently decided)

- **"Every screen", not just the tokens.** The requirement names the tokens; the orchestrator's note and the device check ("text sizes S/M/L on every screen incl. combat") ask for the combat screen and every screen. Converting only the tokens would leave most text fixed, which is the partial behaviour the user already saw. This plan converts every CSS text size and keeps a short, reasoned allowlist for non-text glyph sizing.
- **Fixing the tokens makes the HUD grow at L for the first time.** Phase 57's own budget put band 2 at about 378px at M on a 411px screen, so at 1.25 it cannot fit unchanged. The executor measures every band at S/M/L (412px wide) and, where a band cannot fit, caps that band's own scale with a comment; the device check confirms.
- **The scale moves to the root element.** Anything outside `#app` (the title and roller screens, sheets mounted on the body) now scales too, which is what "every screen" means. The executor confirms nothing relied on the `#app` scoping.
- **Slider taps still work.** CONTEXT allows a tap on the track; a tap commits the tapped level, exactly like a native range input tap.
