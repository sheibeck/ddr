## Decisions Made

- `scrollReadOdds` returns one finished sentence per reader rather than a struct of parts — the two SCROLLS rows only ever need to append a single string, matching how `GEAR_COPY.scrollDesc`/`COMBAT_MENU_COPY.scrollDesc` were already consumed.
- The two automatic readers short-circuit before any band math, mirroring `readScroll`'s own branch order in `engine/magic.js` (magicUser/runes never roll; only the `intel` path calls `scrollReadBands`).
- `CLASS_NOTE`'s three new clauses are additive sentences appended to the existing voice, never a rewrite — keeping every previously-tested substring of the three notes intact while still satisfying "every affected class's descriptions state the new rules."
- Confirmed via a full parity run (56/56, zero fixture diffs) that neither `CLASS_NOTE` nor `FIGHTER_SKILLS[...].txt` is ever serialized into engine state, so the only DOM changes this plan produces are the three declared shell-snapshot fixtures.
