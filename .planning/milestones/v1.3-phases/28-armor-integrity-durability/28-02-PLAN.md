## Formatter contract (planner's discretion, locked for Plans 02 and 03)

`armorDisplay(c)` reads `const av = armorSoak(c)` (engine/derived.js) and the worn scalars, and returns a plain object:

| Field | Value |
|-------|-------|
| `worn` | `Boolean(c.armor && c.armor !== "Nothing" && c.ar > 0)` — a real worn piece exists (an Unequip control applies, even when destroyed) |
| `destroyed` | `worn && c.armorWP <= 0` |
| `magic` | `av.magic` (Cloak of Armor carried — any class) |
| `current` / `max` | `worn ? c.armorWP : 0` / `worn ? c.armorMax : 0` (the WORN piece's pool, never the cloak's) |
| `ar` | `av.ar` (effective: take-the-better when the cloak is present, else `c.ar`; 0 when bare) |
| `label` | `magic ? "Cloak of Armor" : worn ? c.armor : "Nothing"` |
| `wornSub` | `!worn ? "AR 0" : destroyed ? "AR " + c.ar + " · destroyed" : "AR " + c.ar + " · " + current + "/" + max + " hp"` (the worn piece on its own, cloak or not — Plan 03's store repair row uses this) |
| `sub` | `magic ? "AR " + ar + " · magic plate, never wears" : wornSub` |
| `under` | `!magic ? null : !worn ? "under the cloak: nothing" : destroyed ? "under the cloak: " + c.armor + ", destroyed" : "under the cloak: " + c.armor + " " + current + "/" + max + " hp"` |
| `line` | `label + " · " + sub` (e.g. `Plate · AR 15 · 6/45 hp`, `Nothing · AR 0`, `Cloak of Armor · AR 15 · magic plate, never wears`) |

`bagArmorText(it)`: `const left = it.left ?? it.wp;` -> `left > 0 ? "AR " + it.ar + " · " + left + "/" + it.wp + " hp" : "AR " + it.ar + " · destroyed"`.

The separator is the same middle-dot ` · ` the sheet already uses (`STUDDED · AR 10`).
