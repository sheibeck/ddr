## Google's Play Games data-collection page (read 2026-10-01) and how each item was mapped

Page: https://developer.android.com/games/pgs/data-collection, read 2026-10-01 (the Data safety help page, answer/10787469, read the same day for the type definitions: Name "How a user refers to themselves... or nickname", User IDs, Photos, Diagnostics, Other actions, the service-provider and user-initiated exemptions).

The page lists, as collected **automatically** by the Play Games Services SDKs: "Game Service" (Gamer Identity: gamertag, avatar), "Analytics" and "Diagnostics" (to improve SDK stability and make product improvements); and, **depending on usage**: game analytics data, achievements and scores, metagame data, saved games. It also says the SDK encrypts in transit (HTTPS), that a player can delete their Play Games account and data through their Play Games profile or Google MyAccount, and that the developer is "solely responsible" for the answer.

| Page item | Declared as |
|---|---|
| Gamer Identity: gamertag | Personal info -> **Name** (collected, not shared, optional with Compete, App functionality, public on the board) |
| Gamer Identity: avatar | Photos and videos -> **Photos** (Play Games SDK row): conservative, because the game never reads, requests or shows the image |
| Diagnostics and Analytics | App info and performance -> **Diagnostics** (Play Games SDK row), purposes Analytics and App functionality |
| Usage-dependent items (scores, achievements, saved games, metagame, game analytics) | Not applicable: Play Games is used for sign-in only |
| Optional | Both SDK rows are "Yes, optional": with Compete off the SDK never starts |

Also declared per D-07: User IDs reworded (the game's Firebase account ID, linked to the Play Games player ID, which is never shown publicly; bug reports may still create it anonymously), and Other actions now names the Google Play Games name. Deletion, Why optional, Shared (the exemption reasoning and both source pages), the console-step notes, and a "Source-level audit (2.3.0)" subsection (no ad or analytics npm package, `play-services-games-v2` the only new dependency, build-level transitive audit deferred to the release build) are in the listing.
