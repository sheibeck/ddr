Transition additions (`firebase/firestore.transition.rules`), on top of a byte-identical copy of the final rules (header excluded):
- Phase 87's deepKey clause: `(d.deepKey == deepKeyOf(d) || d.deepKey == d.floor * 1000000 + (999999 - d.steps))`.

- create = `<the final create expression> || (<auth, uid, id and isValidBoardRun clauses> && isLegacyHandle(request.resource.data.handle) && !isNamed(request.auth.uid) && !exists(banned))`.
- update = `request.auth != null && !isNamed(request.auth.uid) && resource.data.uid == request.auth.uid && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['handle']) && isLegacyHandle(request.resource.data.handle)`.
