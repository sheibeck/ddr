# Phase 91.2 Plan 07: Account copy, state and controller for Play Games names Summary

The account surfaces now speak Play Games: the account block, title chip and menu face show the verified name's initials avatar, a SIGN IN WITH PLAY GAMES row replaces RE-ROLL HANDLE when Compete is ON and the player is signed out, one rail card per launch says runs are waiting, every 2.3 player gets one welcome card naming their public Play Games name, and board rows mask names that hit the safety list. Nothing was deployed and no live call was made.

## Behaviour

- **Views.** Chip and menu face: no name gives the pending face / plain ☰; name and Compete ON gives the initials avatar; name and Compete OFF gives the dim glyph. Sheet identity status: Compete OFF, then busy (SIGNING IN), out (NOT SIGNED IN), unavailable, then ON THE BOARD with a name or NAME PENDING without. `signIn.visible` is Compete ON and signin out / busy / unavailable; `disabled` is busy. Erase is disabled with Compete OFF, no name, or busy.
- **Controller.** Boot reads settings and `identity.snapshot()` in the same tick and never calls the board. `setCompete(false)` persists, disarms erase, purges; `setCompete(true)` persists and asks `board.session()` once (not a bare flush). `sessionChanged` maps signedIn / signedOut / unavailable and ignores offline / error / off and everything while Compete is OFF. The erase card names the name captured at the confirming tap. `boardAcked` welcomes once with a name and persists `nameWelcomed`.
- **Settings.** `nameWelcomed` sits where the old welcome flag was; a stored blob carrying the old flag reads back without it (so 2.2 players see the disclosure once), tested with the old key built from fragments.
- **Board.** Flagged poster names show `Someone Unprintable`, "?" initials and a neutral grey on rows (including the player's own listed and pinned rows) and in the standing line; other row fields are unchanged. YOUR DEAD rows (rolled hero names) are never masked. Legacy `@handle` rows render normally, initials from the same rule.
- **nameInitials.** "Moss Knuckle" MK, "mossKnuckle" MK, "dev_delver" DD, "Xx99" X9, "@mossjaw" MO, "" "?".
