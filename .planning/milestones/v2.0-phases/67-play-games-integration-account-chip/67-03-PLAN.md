- `{ compete: boolean, status: "off" | "pending" | "signedIn" | "signedOut", player: { id, displayName } | null, welcomed: boolean }`

Sheet view contract (67-07 renders it; pin it identically):
- `title`: string
- `identity`: { face: "avatar" | "nobody" | "pending", initials, bg, glyph, name, status }
- `action`: null | { id: "signIn" | "stopCompeting" | "pending", label, disabled }
- `help`: string ("" for none)
- `compete`: { label, on: boolean, options: [{ value: true, label }, { value: false, label }] }
- `settings`: { label }
Chip view contract: { face: "avatar" | "nobody" | "pending", initials, bg, glyph, label }. For "avatar", initials and bg are set and glyph is ""; otherwise initials and bg are "" and glyph is the nobody glyph.
