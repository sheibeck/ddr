<objective>
Add the ONLY engine change Phase 22 permits: a dev-only `force` option on `newRun(seed, exclude, { startDepth, force })`, threaded into `rollCharacter(rng, exclude, force)`, that substitutes the RESULTS of the class d6 / sub d8 / race d8 draws while still consuming those draws — so every later chargen draw (intel, baseWP, skills shuffle, phobia, temperament, motive, potions, cloak, grimoire, name) sits at the identical rng cursor and the same seed yields the same maze and encounter stream for every forced combo (paired comparison). Prove it with a dedicated determinism test file.

Per 22-CONTEXT.md "Forcing a class/sub/race (HARN-01)": precedent is the Phase 21 `startDepth` dev option (D-13/D-14) — omitted by every real caller, default path byte-identical, no new serialized field, `dev` flag untouched by `force`. Fridgian Samurai is canon-impossible and is REJECTED (thrown), never bypassed.

Purpose: HARN-01 — a forced Troll Summoner and a naturally rolled one are the same character. This seam is what makes Phase 22's 143-cell matrix a class measurement instead of a maze lottery.
Output: `engine/character.js` + `engine/state.js` with the `force` option and updated JSDoc/draw-order header; `test/determinism/forced-chargen.test.js`; parity suite still green with zero carve-outs.
</objective>
