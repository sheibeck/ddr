## Assumptions locked by this plan

- **FOE-05 (edge probe unclassified -> explicit assumption):** "invented abilities only where a depth band has no canon caster" is met by inventing no new spells: every bolt borrows a canon SPELLS dice shape; drain/heal/summon/breath are the creatures' own canon notes. No depth band lacks a caster (Krupke t2, Drudge/Djinni/Drake t4, Drudge/Djinni/Vampire/Stalka t5), so no invented ability was needed.
- Kit ORDER is the D-04 cast priority. Every kit lists its bounded (`every`/`uses`) abilities first and an unbounded fallback last, so a caster still has something to cast when its strong abilities are cooling down, and its strongest bolt can never be cast on consecutive foe turns (FOE-06).
- Djinni's "4x/day" is per ENCOUNTER (D-05); the `every` cadences on two of its four abilities are a planner-discretion interleave so the kit does not fire the same ability four turns running.
- Drake keeps `sp.dmg` 2d10+4 for melee exactly as Phase 18 pinned it (the yardstick AFTER table and the D-18 content pin depend on it); the breath is a SEPARATE bolt with the same dice. Retuning either is Phase 21's job.
- The Djinni flee threshold is data (`sp.fleesBelow: 0.25`) rather than a name check, so the flee behaviour is visible in content and reusable by Phase 21 without an engine edit.
