- **FOE-07 (edge probe unclassified -> explicit assumption):** "the SAME canon rule" is implemented as one function object; the two callers (`castSpell` reads the FOE's intel; 19-03's resolver reads the HERO's `c.intel`) pass different intel values but share the gate, the die, and the comparison. `rolled` is an additive return field beyond D-07's `{ resisted, roll }` so callers can distinguish "no roll happened" from "rolled and failed" without inspecting `roll === undefined`.
