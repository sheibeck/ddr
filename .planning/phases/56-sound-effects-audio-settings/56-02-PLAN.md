    `groupsForDispatch(actionType, events, ctx)` — an exported PURE function returning an ordered array of group ids (or the literal five `enemy-*` clip ids for the cry, see below). Rules, in this exact order:
    1. Guard: if `events` is not an array, treat it as empty. Never throw on null, undefined, a non-array, or an array holding malformed entries without a `type`.
    2. Synthesized step clip, emitted FIRST, before any event-derived entry: when `actionType` is `move` AND `ctx.stepped` is true AND no event type in the list is in `STEP_SUPPRESSING_EVENTS`, push `water` if any event type is `waded`, otherwise push `walk`. Exactly one step clip, never both.
    3. Walk the `events` array in array order. For each event: if its type is `combatJoined`, resolve the cry through `FAMILY_CRY[ctx.combatType]` and push that clip id when it resolves (push nothing when `ctx.combatType` is absent or unknown — an engine-impossible state, documented as the one silent branch); otherwise look the type up in `EVENT_CLIP_GROUP` and push the group id when found.
    4. De-duplicate by pushed identity, keeping the FIRST occurrence — two `struck` events in one dispatch collapse to one `hit`.
    5. Truncate to `DISPATCH_CLIP_CAP` entries, keeping the first 3 in the order produced.
    6. Return `[]` for an empty list, an all-unmapped list, or a missing/garbage `events` argument. The empty path must touch no counter and allocate no state.

    `createVariation()` — an exported factory returning an object with a single `next(groupId)` method, closing over a plain `Map` of per-group counters. `next(groupId)` resolves `CLIP_GROUPS[groupId]`; when the group is unknown it returns `null` without throwing and without touching the map; when the group has exactly one clip it returns that clip without attempting any no-repeat guarantee and without touching the map; otherwise it reads the current counter (default 0), returns `group[counter % group.length]`, and stores `counter + 1`. This modulo round-robin IS the shuffle-bag: for size 2 it strictly alternates, for size 3 it cycles 0,1,2 and never repeats back-to-back. Comment that a counter, not a draw, is what keeps this phase incapable of perturbing engine determinism.

    A module-level default variation instance created from `createVariation()`, used when no variation is passed in.

Drops any `null`. Returns the ordered array of concrete clip ids. `variation` defaults to the module-level instance so the shell never has to thread state; tests pass their own instance so they need no reset hook.
