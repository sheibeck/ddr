# Phase 97.1 Plan 03: Re-pin the cross-surface tests and the 2.4.0 DRAFT Summary

The two cross-surface test files now pin flavour-only: no rules control or body on any surface, every rules sentence still pinned on the model or content table that carries it, and the 2.4.0 DRAFT says the exact rules sit behind the scenes.

## What was built

- **Task 1 (019e8166):** docs/patch-notes/2.4.0.md. The Settings "Always show the rules" bullet is deleted. Both "one tap away under RULES" tails now read "sitting behind the scenes". The Headline, DRAFT line, Items & gear, Monsters & difficulty and Screens text are untouched. The file validates and contains neither RULES nor "Always show the rules".
- **Task 2 (bf7a1f51):** rules-surfaces.test.js. Imports of the old component, the `beforeEach` reset and the `tap` helper are gone. New helper `rulesNodes`/`assertNoRulesControls` (class starting `mw-rules-`). Every surface case is re-pinned to flavour-only plus a model-side pin: Grimoire (`grimoireViewModel` txt and resistNote), combat SPELLS/ITEMS/ABILITIES/SING (`vmRow.rules`, `vmRow.lead`), find card, rail dismiss handler (names no `mw-rules`), lock rule (bare `.cb-row`), Gear WORN/BAG/CONSUMABLES (`gearConsumablesModel` rules), Gear sheet (j) Anklet container hidden with statKeys `["effect"]`, (k) weapon plain `p.mw-gsheet-note.mw-gsheet-stat` rows with no voice line, new (j2) bagged Studded rows, store (bare buttons, `storeRowLayer().rules`), sell list, drop shelf (bare buttons, clean tap drops the true index), loot list, dossier/trait/abilities/skills/Final Sheet, chip cards (`assertFlavourFirstCard` keeps `lines[0].rules` byte for byte), UP YOUR SLEEVE. `assertRulesTapStaysPut` and the tap/repaint/Always tests are deleted. The patch-notes test pins "behind the scenes" and no RULES/Always line.
- **Task 3 (c77fbe70):** flavor-sweep.test.js. `visibleText` reads a rules body; `rulesBodiesUnder`/`rulesControlsUnder` replace the old finders; new `assertS3(root)`, `assertS4(root, text)`, `assertShown(shown, text)` and `indexWith(extra, allowed)`. Probe contract is `{ flavours, extraRules, shown? }`; every old `bodies` array is folded into `extraRules`. The Gear sheet probe splits formatter rows by key: non-effect rows in `shown`, effect rows plus `weaponMundane`/`weaponMagic` in `extraRules`; a worn Leather armour sheet is added. Single pass (no Always loop). Teeth tests rebuilt on a hand-built fragment: S2/S3/S4 failures, a stat row is never a body or control, exemption is exact string only, and a regressed effect row drawn as a stat-row-shaped element goes red on S2.
