Fake Play Games code (from 91.2-01 `createFakePlayIdentity`): `fake:<encodeURIComponent(playerId)>:<encodeURIComponent(displayName)>:<n>`.

`accounts:signInWithIdp` request body: `{ requestUri, postBody: "code=<code>&providerId=playgames.google.com", returnSecureToken: true, returnIdpCredential: true, idToken? }`. 200 body: `{ localId, idToken, refreshToken, expiresIn: "3600", providerId: "playgames.google.com", federatedId, displayName, isNewUser }`. ALREADY_LINKED with returnIdpCredential: 200 `{ errorMessage: "FEDERATED_USER_ID_ALREADY_LINKED", providerId, federatedId }` (no tokens); without it: 400 with that message. Errors: 400 `OPERATION_NOT_ALLOWED` (provider disabled), 400 `INVALID_IDP_RESPONSE` (bad or reused code), 400 `INVALID_ID_TOKEN`.

`accounts:lookup` `{ idToken }` → `{ users: [{ localId, displayName?, providerUserInfo: [{ providerId, rawId, federatedId, displayName }] }] }`; bad token → 400 `INVALID_ID_TOKEN`; expired → 400 `TOKEN_EXPIRED`.
`accounts:update` `{ idToken, deleteProvider?: string[], displayName?, deleteAttribute?: ["DISPLAY_NAME"], linkProviderUserInfo? }`: linkProviderUserInfo → 400 `ADMIN_ONLY_OPERATION`; otherwise applies and answers 200 `{ localId, providerUserInfo }`.

`runPgsProbe({ playIdentity, fetchFn, config = FIREBASE_CONFIG, playConfig = PLAY_GAMES_CONFIG, now = Date.now })` → frozen report `{ v: 1, at, steps: [{ id, ok, facts }], gates: { G1, G3, G4, A3, A4, A6 } }`, each gate "pass" | "fail" | "check" (needs the human's eye) | "skip".
