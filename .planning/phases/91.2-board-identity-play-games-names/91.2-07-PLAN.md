<interfaces>
Account state (`src/browser/account.js#normalizeAccountState`): `{ compete: boolean (true unless exactly false), name: string | null (sanitizeBoardName), signin: "unknown" | "in" | "out" | "busy" | "unavailable" (default "unknown"), erase: "idle" | "armed" | "busy", welcomed: boolean }`.

Faces: name null → "pending"; name and Compete ON → "avatar" (nameInitials(name), avatarColour(name)); name and Compete OFF → the dim off glyph. Menu: Compete ON and a name → avatar and the named label; otherwise the plain ☰.

Sheet view: `{ title, identity: { face, initials, bg, glyph, name, status }, compete, help, signIn: { id: "signin", label, visible, disabled }, erase: { id, label, armed, disabled }, settings }`; `signIn.visible` = Compete ON and signin in out / busy / unavailable; `signIn.disabled` = signin busy; `erase.disabled` = Compete OFF, no name, or busy. Status: Compete OFF → off; busy → signingIn; out → signedOut; unavailable → unavailable; a name otherwise → on; no name → pending.

`accountCard(kind, name)`: "welcome" and "erased" need a valid name (else null); "eraseFailed" and "signinNeeded" take none.

Controller (`createAccountController({ identity, board, settings, notify, compete, armMs, setTimer, clearTimer })`):
- identity seam: `snapshot()` → `{ name }` (local, no network).
- board seam: `session()`, `signIn()` (both resolve the 91.2-06 info), `erase()`, `purge()`, `flush({ force })`.
- returns frozen `{ boot, setCompete, signInTap, sessionChanged, eraseTap, disarmErase, boardAcked, state, chipView, sheetView, menuView, subscribe }`.
- `sessionChanged(info)`: signedIn → signin "in" and name = info.name; signedOut → signin "out" and, once per launch while Compete is ON, raise "signinNeeded"; unavailable → signin "unavailable"; offline / error → signin unchanged; off → nothing.
- `signInTap()`: Compete ON and not busy → emit busy → `board.signIn()` → `sessionChanged(result)`; a rejection → signin "out".
- `setCompete(true)` → persist, then `board.session()` (not a bare flush); `setCompete(false)` → persist, purge.
- `boardAcked()`: the first acknowledgement ever with a name (nameWelcomed false) persists `nameWelcomed: true` and raises "welcome" naming the name.

Renderers (`renderAccountSheet`, `renderAccountMenu`): a SIGN IN row (`button.mw-acct-action`, `data-action="signin"`, hidden when not visible, disabled when busy) where the re-roll row was; handler `onSignIn(event)`.

`nameInitials(name)` (`src/browser/leaderboardView.js`, replaces the per-handle-word rule): strip a leading "@"; split on spaces, underscores, dots, hyphens, camelCase and letter/digit boundaries; first letters of the first two parts, upper-cased; one part → its first two letters; nothing → "?".
</interfaces>
