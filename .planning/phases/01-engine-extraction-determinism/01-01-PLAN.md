## Phase Goal

**As a** Mazeworld game client (the browser UI today, a future multiplayer host tomorrow),
**I want to** resolve every rule through one deterministic `applyAction(state, action) → {state, events}` call over pure-data content and a seeded PRNG,
**so that** the same seed and inputs always reproduce the same run, state saves and restores losslessly, and the prototype's behavior is preserved with zero regressions.

> Refactor-adapted user story: the ROADMAP goal is an outcome statement; the "user" of this
> engine phase is the game/UI/future-multiplayer consumer of `applyAction`. This plan
> delivers the scaffold + RNG that the skeleton and all slices build on.
