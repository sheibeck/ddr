<objective>
Extract the maze/floor generator (genFloor, bfs, reveal) into a pure engine/maze.js that takes
an injected seeded RNG instead of the global Math.random, reproducing the prototype's recursive
backtracker + loop-carving + farthest-cell exit + feature scatter + dark-zone blobs + one-way
doors exactly — including the fixed 5-floor Gate. This is the first parity-verifiable pure
function and a prerequisite for newRun (plan 01-05) and movement/descend (plan 01-07).

Purpose: genFloor is the heaviest RNG consumer in the game and the cleanest determinism target
("same seed → same maze"). Getting its RNG-consumption order byte-faithful is what lets the whole
parity harness work, since every later floor the run visits comes from here. The two inline
`Math.random()` sites in the loop-carving step (prototype lines 1190-1191) must consume the
injected rng in the identical order, or every downstream parity comparison drifts.

Output: engine/maze.js + a unit test + a determinism test.
</objective>
