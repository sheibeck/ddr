## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser input → Action → applyAction | D-pad/keyboard events become move Actions; the engine's validateAction (plan 01-05) rejects malformed ones. |
| load() → rehydrate (at boot) | The adapter rehydrates the active-run state from localStorage via engine/saveState.js (plan 01-06), fail-closing to newRun on a bad save. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-07a | Tampering | corrupt active-run save at boot | low | mitigate | Adapter loads through validateSave/rehydrate (01-06), fail-closing to newRun; a tampered save cannot crash boot. |
| T-01-07b | Tampering / DoS | malformed move Action | low | mitigate | validateAction no-ops an illegal dir; movement itself no-ops an illegal move without mutating state. |

No package installs (T-01-SC N/A). The adapter is presentation glue; the engine stays DOM-free.
</threat_model>
