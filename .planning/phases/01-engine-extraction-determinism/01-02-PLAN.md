<objective>
Extract the prototype's rules tables (mazeworld.html lines ~493-914) into standalone
pure-data modules under content/, converting every embedded RNG closure (`d:()=>D(6)`,
`dmg:()=>D(8)`, `uses:()=>D(6)`, `loss:()=>2*D(6)`, `dmg:()=>D(20)*5`, etc.) into plain
dice-notation data (`{n,sides,bonus}`) or index/table data the engine resolves later.

Purpose: ENG-03 (content as pure data) and ENG-02 (no RNG in content) are the SAME refactor
pass — the ~79 dice-closures embedded in these tables ARE the `Math.random()` coupling hidden
as data. Moving the tables without de-closuring them is a false "step 1 done". This plan makes
content 100% JSON-serializable so the engine can be pure.

Output: ~19 content modules + a barrel index + a content-values test. No logic — data only.
</objective>
