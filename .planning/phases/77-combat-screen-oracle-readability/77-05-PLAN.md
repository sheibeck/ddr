## Flagged assumptions (surfaced, not silently decided)

- **CMBUI-11 edge probe: unclassified, reviewed manually.** Resolved as: the note is keyed on adjacency (a scrollTooAdvanced directly followed by a scrollCast of the same spell); the note never precedes the cast on any surface; a standalone scrollTooAdvanced keeps a non-refusal line so the coverage guards and a hypothetical future caller still narrate; only Magic Users reach this event after 75.1-06 ("only Magic Users reach that event").
- **Why a presentation stamp instead of an engine reorder:** the engine pushes scrollTooAdvanced before scrollCast because it checks the copy before the free cast. Moving the push would be an engine change purely for wording. The stamp follows decorateMisses' precedent (a presentation-only field the adapter adds before formatting), and the engine's event list keeps its order.
- **Out of combat, a combat-only spell** read from a scroll (Fireball in a corridor) still gets castSpell's own genuine combatOnly refusal after the cast line; that refusal is real and outside CMBUI-11 ("a scroll read in combat that casts").
