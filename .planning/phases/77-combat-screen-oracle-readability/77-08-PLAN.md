## Flagged assumptions (surfaced, not silently decided)

- **The "small description sheet" is the existing combat-legal condition card** (Phase 71's `window.mzConditionCard`, rail.js conditionCard), the same card a HUD chip tap raises in a fight; no new sheet component.
- **The HUD strip stays** (it is the map surface and carries squares-counted and map-only chips); in a fight the hero's fight chips therefore appear both in the strip and under the hero card. Both read the same enumerator and the same text.
- **"In the dark" becomes "Dark"** so every fight chip label is one word (the house style); no test pins the old label.
- **Ability chip labels** are one word each (for example "Sidestep", "Roaring", "Riposte", "Taunting", "Smoke"); the ability's own name and text still appear in the tap sheet.
- **The combat screen's fixed px sizing** (no S/M/L text scaling) is kept for the chips, matching the rest of the combat screen; text-size scaling of the combat screen belongs to Phase 78.
