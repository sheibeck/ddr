<interfaces>
- `tools/tune-difficulty.mjs --seeds=N [--start-depth=N] [--control-rotation]`: single-threaded; prints its whole report at the end (nothing until then). The seed list is `i*7919+1`. The report ends with `Outcome: <n> dead, <n> stuck`. The per-floor survival block prints one `L=<floor>  reached=<n>  deaths=<n> ...` row for every floor from the start to the deepest death. `reached` counts every run whose death depth is at least L, stuck runs included. It then prints a `reach-20: X%` line (all runs) and a `verdict:` line for floors 1-12.
- `tools/tune-classes.mjs --seeds N --workers N [--sub X] [--race X] [--start-depth N] [--out PATH]`: prints the text matrix to stdout and writes the JSON report to `--out`. The text ends with the `BY CLASS`, `BY SUBCLASS` and `BY RACE` roll-ups. The full matrix is 143 cells (3 classes × 8 subs × 6 races, minus Fridgian Samurai). With `--seeds 10`, each race's roll-up is the same 24 forced cells and the same seeds as `--race <Race> --seeds 10`. That is the command behind tools/readouts/75.2-01-races-before.txt, so the Elven, Dwarven and Troll rows compare like for like.
- `tools/fit-difficulty.mjs --objective=tail --fresh=gate|always --dials=<json> --workers=4 --log=<jsonl> --transcript=<txt>`: one evaluation of every TAIL_SLICE, logged as one JSON row with `summaries`, `score`, `verdict`, `misses`, `constraints` and `elapsedMs`. `--dials='{}'` means the shipped DIALS of the code it runs on, because `setDialsForTuning` merges onto DIALS. `--transcript` appends every stdout line itself, so stdout needs no redirect.
- `tools/lib/tail-score.mjs`: TAIL_SLICES (fresh 1,000; deep12/20/30/40 200; rot20/30/40 40 Human Sorcerer with controlRotation; troll20 40 Troll Summoner, report only), TAIL_TARGETS, summarizeSlice.
