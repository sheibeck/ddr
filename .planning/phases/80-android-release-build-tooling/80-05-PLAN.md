<interfaces>
- Package and activity: com.darktierstudios.delvedierepeat / .MainActivity. Launch with `adb -s <serial> shell monkey -p com.darktierstudios.delvedierepeat -c android.intent.category.LAUNCHER 1`.
- Boot readiness: `adb -s <serial> wait-for-device`, then poll `adb -s <serial> shell getprop sys.boot_completed` for "1". Dismiss the keyguard with `input keyevent KEYCODE_WAKEUP` and `wm dismiss-keyguard`.
- Screenshots: `adb -s <serial> shell screencap -p /sdcard/s.png` then `adb -s <serial> pull /sdcard/s.png <dest>`. The executor opens each PNG with the Read tool to judge it.
- UI driving: `adb -s <serial> shell uiautomator dump /sdcard/ui.xml` and pull it; WebView content appears as nodes with text and bounds; tap a node's centre with `input tap x y`. The title button reads ENTER; the roller's primary button is #mw-roller-cta (read its label in mazeworld.html). A release build has WebView debugging off, so CDP is not available on device.
- Navigation mode overlays: `cmd overlay enable-exclusive --category com.android.internal.systemui.navbar.gestural` and `... .navbar.threebutton`. Cutout emulation: `cmd overlay enable-exclusive --category com.android.internal.display.cutout.emulation.tall` (disable it afterwards with `cmd overlay disable` on the same package).
- Rotation: `settings put system accelerometer_rotation 0` then `settings put system user_rotation 1` (landscape) and back to 0. Fold: the emulator console commands `adb -s <serial> emu fold` and `emu unfold` on a foldable AVD.
- Logcat: `adb -s <serial> logcat -c` before launch, `adb -s <serial> logcat -d` after.
- Debug keystore for a scratch emulator signature: %USERPROFILE%/.android/debug.keystore, store and key password "android", alias "androiddebugkey".
</interfaces>
