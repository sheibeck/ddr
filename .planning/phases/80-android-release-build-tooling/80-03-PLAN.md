## Research correction (accepted by the orchestrator)

CONTEXT.md said: declare `android:appCategory="game"` "and let large screens (sw >= 600dp) rotate and resize around the column. Android 16 ignores orientation locks there anyway." 80-RESEARCH.md ("Large Screens / DROID-03", citing developer.android.com's Android 16 behaviour changes) showed the exemption runs the other way: for apps targeting API 36, orientation, resizability and aspect-ratio restrictions are ignored on displays with smallest width >= 600dp, **except for games** declared through `android:appCategory`. So declaring the game category keeps the portrait lock honoured; it does not make large screens rotate. The user-facing outcome in CONTEXT (a deliberate letterboxed portrait column on tablets, foldables and Chromebooks) is unchanged. The column is still needed because a large-screen **portrait** window is 700-1200 CSS px wide, far wider than a phone's 360-430. Both the manifest portrait lock and the JS `ScreenOrientation.lock` stay. This correction is recorded here and in docs/ANDROID-DISPLAY.md.

The body-level containing block covers future overlays without per-overlay rules, and 80-04 re-runs the letterbox check on the final code to prove it.
- **Column width 480 CSS px** (Claude's discretion per CONTEXT): just above the widest common phones (about 430-450), so every phone keeps its full-width layout and every large screen gets a phone-shaped column.
- **CSS, not native, letterboxing** (Claude's discretion per CONTEXT): the OS letterbox colour is system-controlled, and CONTEXT asked for parchment-dark gutters. On a tablet whose OS also letterboxes the portrait-locked game inside a landscape display, the result is the OS letterbox around a portrait window with this column inside it; 80-05 records what the emulator does.
- **Play's display-configuration warning:** Android's docs say games are exempt, and the warning's precondition no longer applies to a declared game. Only the next Play pre-launch report proves it; that check joins the milestone-close list, with "consciously accepted" as the recorded fallback verdict.
