## Facts established while planning. Re-verify, and record them in the SUMMARY.

- **adb is not on PATH on this machine.** In a Bash tool shell `command -v adb` finds nothing. adb lives at `C:/Users/Dell/AppData/Local/Android/Sdk/platform-tools/adb.exe`, which is `sdk.dir` from the git-ignored `android/local.properties` plus `platform-tools`. `ANDROID_HOME` and `ANDROID_SDK_ROOT` are both unset. That is why the tool resolves adb itself instead of trusting PATH.
- **`am start -W` output shape** (Android 10+, one block per launch): a `Starting: Intent { cmp=<pkg>/<activity> }` line, then `Status: ok`, `LaunchState: COLD` (or WARM / HOT), `Activity: <pkg>/<activity>`, `TotalTime: <ms>`, `WaitTime: <ms>`, and `Complete`. A failed launch prints an `Error:` line and has no `TotalTime`. Lines can end in CRLF when captured through adb on Windows, so strip a trailing carriage return before matching.
- **What `TotalTime` brackets on this app is not asserted anywhere.** `capacitor.config.json` sets `SplashScreen.launchAutoHide: false`, so the native splash holds until the web boot calls `hide()`. Whether the platform's first-frame timestamp includes that hold depends on how the splash plugin defers the first frame. The tool measures what the platform reports. Plan 60-02 writes the caveat into `docs/PERF-BASELINE.md`. Do not claim either way in code comments.
- **Nearest-rank p95 at n = 10 is the slowest run**, because `sorted[Math.ceil(0.95 · 10) − 1]` is `sorted[9]`. This is expected and pinned by a test. The cold-start threshold is on the median, which one outlier cannot move.
- **Main-guard house pattern:** `tools/bridge-doc.mjs:100` and `tools/ident-sweep.mjs:378` both use `path.resolve(process.argv[1] || "") === url.fileURLToPath(import.meta.url)`. `tools/ident-sweep.mjs` exports `stripJs` / `stripHtml` for comment-stripped source checks.
- **`node --test` (the `npm test` script) collects every `*.test.js`, including the whole of `test/`.** Keep all fixtures inline in the test file, or write them to `os.tmpdir()` at test time. Do not add a `.js` fixture under `test/`, because it would be collected as a test file.
</discovery>
