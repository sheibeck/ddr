The RunSummary shape this module ranks (engine/death.js#buildRunSummary; Plan 65-04 adds the last four fields):
`{ name, race, sub, cls, level, sp, floor, day, steps, gold, kills, cause, note, epitaph, when, season, seed, acts, hash }`
Every field is a primitive. Legacy graveyard stones carry the first 15 and none of season/seed/acts/hash. Some very old stones are partial objects such as `{ name, cause }`.

The contract this plan exports (Plans 65-03, 65-04 and 66 consume it):
- `RUN_HASH_FIELDS`: frozen `["season","seed","acts","floor","steps","day","kills","gold","sp","level","race","sub","cls","name","cause"]`
- `HASH_DELIMITER`: `"\u001f"`
- `fnv1a32(str) -> number`: unsigned 32-bit
- `runHash(run) -> string`: 8 lowercase hex
- `BOARD_TOP_N`: `10`
- `BOARD_IDS`: frozen `["deep","lean","combo","days","kills","purse","yard"]` (the mock's tab order: DEEPEST, LEANEST, LINEAGE, LONGEST, BUTCHERY, PURSE, GRAVEYARD)
- `RANKED_BOARDS`: frozen `["deep","lean","days","kills","purse"]`
- `compareRuns(board, a, b) -> number`: negative when a ranks above b, 0 on a full tie
- `boardValue(board, run) -> number`
- `lineageKey(run) -> string`
- `emptyBests() -> BestsRecord`
- `sanitizeBests(raw) -> BestsRecord`
- `updateBests(record, summary) -> { record, newBests, first }`: newBests is an array of board ids, ordered as in BOARD_IDS
- `backfillBests(graves) -> BestsRecord`
- `sortGraveyard(graves) -> RunSummary[]`

BestsRecord: `{ v: 1, runs: { [hash]: RunSummary }, boards: { deep: string[], lean: string[], days: string[], kills: string[], purse: string[] }, lineage: { [combo]: { count: number, best: string|null } }, last: string|null }`
