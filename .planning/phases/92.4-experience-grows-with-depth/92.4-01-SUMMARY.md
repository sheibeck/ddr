# Phase 92.4 Plan 01: Experience grows with depth Summary

Every foe experience grant is now multiplied by 1 + 0.10 x (depth - 1), and an elite also by 1 + 0.1 x rank, through one new dial (`XP_DEPTH_SCALE`) and one rounding, so a goblin on floor 5 pays 1.4 times what the same goblin pays on floor 1.

## The formula as built

```
killSpFor(c, f, roll, depth = 1) = Math.round(roll * f.lvl * mul * xpFoeMulFor(depth, f.elite))
  mul               = 5 * (race spMul) * (Barbarian 0.5) * (Apprentice below level 3: 2)      (unchanged)
xpFoeMulFor(d, r)   = perDepth === 0 ? 1
                    : (1 + perDepth * (safeDepth(d) - 1)) * (1 + FOE_ELITE.hpPerRank * r)    (perDepth = DIALS.XP_DEPTH_SCALE.perDepth = 0.1; r = f.elite or 0)
killFoe:  gained = killSpFor(c, f, roll, state.floor.depth); heroShare = round(gained / shares) when shares > 1; spGained = heroSpFor(heroShare)
parley:   per live foe, killSpFor(c, f, rng.d(6), state.floor.depth), split as a kill's is, then heroSpFor(round(sum))
```

Floor 1 of a plain foe is exactly 1 (`1 + 0.1 x 0`), so floor 1 pays as before. The multiplier is 1.1 on floor 2, 1.4 on floor 5, 2 on floor 11, 3 on floor 21. Pure arithmetic: no rng draw is added or moved. The descend bonus (`heroSpFor(40 + 30 x floor)`) and the table-four XP dots (+10, +25) never read the dial (stated in the dial's JSDoc, the ROLL-LEDGER section, and pinned by a test).

## Open question for the user

The user said: "if that is going to drastically affect the difficulty curve, we should talk about that." It was not measured (ruled out), so it is not known whether the curve moves much. The reasoning only: faster leveling below floor 1 raises hit points and the strike die sooner on every deeper floor, which eases the curve the Phase 79.2 lock fitted (fair-bot p50 death depth 5). The one switch that would measure it is `--dials '{"XP_DEPTH_SCALE":{"perDepth":0}}'` against the shipped 0.10.

## Human verification

Device checks (Pixel 7, debug build). The hero's HERO_SP_SCALE (0.23) rounds each figure, so compare ratios over several kills rather than one.

1. **Floor 1 is unchanged.** On floor 1 a kill's "(+N XP)" is what it was before the change (a level-1 foe with a d6 of 4 pays 5 for a Human Soldier: 4 x 5 x 0.23 = 4.6, rounded).
2. **Deeper pays more.** Kill the same kind of foe on floor 5 and on floor 11: the "+N XP" is about 1.4 and about 2 times the floor-1 figure for the same foe level and roll (the foe's own level also rises with depth, so compare against the same level and the same d6 if you can read it, or just see the figure climb faster than before).
3. **An elite pays more again.** An elite (a titled foe from the depth where level-5 foes gain ranks) pays more than a plain foe of the same level on the same floor, by about 10% a rank.
4. **A won parley.** Win a parley on a deep floor: the "spGained" total is the full sum of every live foe's scaled pay (it was flat before); with a Joiner present it is split as a kill's is.
5. **Unchanged sources.** The descend bonus on taking the stairs and the +10 and +25 XP table-four dots are the same as before (they do not grow with depth).
6. **Leveling feels faster at depth, not on floor 1.** The first level-ups should arrive no sooner than before; deeper levels should come noticeably sooner. If the difficulty curve feels clearly easier at depth, that is the open question above: the dial is `DIALS.XP_DEPTH_SCALE.perDepth` (0.1; 0 = today).
7. **No text claims a flat amount.** Nothing in the Hero tab, the parley button text or the patch notes says a kill pays a fixed figure; the 2.3.0 patch notes list "Experience: the same at any depth → +10% per floor below the first."
