## Flagged assumptions

- **Row order.** D-08 puts REPORT A BUG "after SETTINGS and before the split line", and D-20 puts PATCH NOTES "next to REPORT A BUG". So the order is SETTINGS, REPORT A BUG, PATCH NOTES, split.
- **The glyphs are Claude's discretion** (CONTEXT). ✎ U+270E is a Dingbat with no emoji presentation. ¶ U+00B6 is Latin-1, so the bundled mono font draws it. ✎ may fall back to a system font on Android; the Pixel 7 checklist item in 79.3-05 checks it renders.
- **Label copy.** The labels live in `HUD_MENU_ITEMS`, whose label is already a registered voice bank (`pick: ["label"]`). The corpus therefore gains `bank:HUD_MENU_ITEMS.4.label` and `.5.label`. Their ledger rows are written by 79.3-05, which owns the phase ledger. The markup label spans duplicate bank text, so the raw sweep skips them.
- **The rows are inert between waves.** Until 79.3-05 and 79.3-07 land, tapping either row just closes the menu. That is the intermediate state inside this phase, never a shipped one.
