## Flagged assumptions

- **"After the title or boot settles"** means one animation frame after `readNotesLaunch` resolves, and only while `#mw-title-screen` is shown. The app always boots to the title screen (initTitleScreen never hides it).
  - If the player has already left the title when the decision lands, the show waits (`notesAutoPending`) for the next time the title is shown, and the version is not marked seen until then.
  - So the notes never pop over the map or a fight.
- **The auto-show reuses 79.3-03's decision.** Same version: none. Changed version, or an upgrade with no seen key but prior app data: show. Fresh install: mark.
- **The link.** `target="_blank"` with `rel="noreferrer"`. In the Android WebView (Capacitor, which has no multi-window), an external https navigation goes through Capacitor's `launchIntent`, which opens the system browser and leaves the game where it was. In the browser dev loop it opens a new tab. The Pixel 7 checklist confirms it.
- **The Close button's text "Close"** is the existing legend-close markup pattern (settings, account). A single word with no ending punctuation is not copy to the corpus, so nothing new is ledgered.
