# Phase 79.3 Plan 02: the GitHub Action that files bug reports (summary)

(The orchestrator wrote this from the executor's returned text. Commits: 71ee0742/3aa97786 (the formatter, RED then GREEN), a01f8f66/7d975515 (the filer, RED then GREEN), d80153da (the workflow, .gitignore and the secrets scan). Merged into master cleanly.)

This is a Node 22 GitHub Action with no dependencies. It turns new Firestore `bugReports` documents into public GitHub issues:
- they never @-mention or #-link anyone;
- they are size-bounded;
- the Oracle sits in a collapsed block;
- the first line carries the marker `<!-- ddr-report:<docId> -->`.

An idempotent lock and reconcile state machine keeps a report from being filed twice, and there's a full dry-run path.
