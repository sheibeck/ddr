## Flagged assumptions

- **Spark plan.** Creating the `(default)` Firestore database and using its free quota needs no billing account. If gcloud refuses because of billing, STOP and put that in front of the user; never enable billing (D-01).
- **Service-account key creation.** An org policy (`iam.disableServiceAccountKeyCreation`) can block key creation. If it does, STOP and bring the user the choice: allow keys for this project, or switch the Action to Workload Identity Federation (a new design decision, not taken here).
- **Key restriction.** The API key gets an API restriction (Cloud Firestore API) only, with no Android-app restriction. The WebView's fetch sends no `X-Android-Package` or `X-Android-Cert` headers, so an Android restriction would refuse every report.
- **The 2.1.0 notes content is not written here.** Per D-18, the orchestrator writes it with the user before 80-04's release build. VERIFICATION lists it as a pending release step, together with `--play` for Play Console and the GitHub Release after the `v2.1.0` tag.
