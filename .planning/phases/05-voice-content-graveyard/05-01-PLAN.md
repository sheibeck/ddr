<objective>
Build the pure, category-keyed voice generator that turns any structured engine event into sarcastic, family-friendly plain-text copy — the foundation VOX-01 rests on. This plan delivers the generator module, the exhaustive event→category map (with a coverage guardrail that fails on any unmapped engine event type), a first-pass weighted variant bank per category, a presentation-local deterministic RNG that never touches the engine's serialized rng state, and the tone/style guide that governs all authored copy.

Purpose: Establish the ONE place structured Events become narrative copy, sitting in a new presentation/content layer OUTSIDE engine/ (engine-purity guard) and OUTSIDE content/'s pure-data zone (the generator function must not live under content/). Generalizes the proven engine/death.js#epitaphFor / fillTemplate weighted-pick + {token}-fill pattern without touching death.js (that stays a permanent, tested carve-out).

Output: presentation/voice.js, presentation/eventCategories.js, presentation/templateFill.js, content/voice-*.js banks + content/voice-index.js barrel, content/VOICE-STYLE-GUIDE.md, and the VOX-01 guardrail tests under test/voice/.

## Phase Goal (MVP user story, derived from ROADMAP Phase 5 success criteria)
**As a** player of Mazeworld, **I want to** see the game narrate my run in a consistent, sarcastic, dark-but-family-friendly voice generated from what actually happened, **so that** the game's comedic identity comes through on every screen instead of a few hardcoded lines.

This plan (slice 1 of 3) delivers the engine that makes that voice possible; slice 2 (05-02) broadens the copy, wires it into the live Oracle log, and proves it family-friendly; slice 3 (05-03) delivers the graveyard screen.
