# Phase 91.1 Plan 02a: The cooldown family Summary

## Deviations from Plan

**1. [Interpretation] Smoke's six rounds.** The ledger says "ready again 6 rounds after the use" and "two of every six rounds". Smoke is a duration ability (effect first), so `cd: 6` would be ready 9 rounds after the use. Built as effect 3 ticks plus `cd: 3` (6 in all, from `abilityReadyAfter`). If the user meant six after the effect ends, it is the one-number change `cd: 3` to `cd: 6` in `content/abilities.js` (and "6" to "9" in the text, `SKILL_TEXT_FACTS` follows by measurement). The Hero tab's out-of-combat state still reads the raw field ("cd 3 rounds" for Smoke), the same convention as Sidestep's "cd 4 rounds"; the in-combat row counts down the true remainder.

**2. [Rule 3 - Blocking] Narration, menu, variants and bot changes landed in Task 1's commit** (the plan lists them under Task 2/3): the new `alreadyOn` refusal needs its narration for the coverage guards, and the menu and bot reads are the same rule as the engine's.

**3. [Rule 2 - Missing critical] Value-ledger checker taught the built verdict.** `test/unit/value-ledger.test.js` required every verdict to name its V numbers, which a `built (91.1-0N)` part cannot; a built part now stands for the cited questions no other part names. `test/fixtures/value-ledger-open.md` (the checkpoint copy) quotes the eight live texts so its doctored-copy tests keep running. VALUE-03's test now reads the three `cd: "fight"` entries that remain.

**4. Narrative ledger file name.** `docs/narrative-pass/why/s-91.1-02a.json` (not `91.1-02.json`): the ledger sorts by file name and the keys chain from quick-task ledgers (`q-...`), so it has to sort after them (precedent: `r-91-10.json`). Part B should chain from it with a name sorting after (for example `s-91.1-02b.json`).

**5. Existing pins re-based** (dated comments name the plan): `once-per-fight`, `once-per-fight-copy`, `abilities`, `abilities-catalog`, `combatMenu`, `characterSheetViewModel`, `class-trims-nrf-copy`, `skill-audit` doctored-copy rows (moved to Silent Step, whose verdict is unchanged), `spell-skill-text-engine` (eight facts now measure the wait), `spell-skill-text-wording`.
