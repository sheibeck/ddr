<objective>
Melee-class Joiners use their own rolled abilities (D: "Joiners (ABIL-05)"): `alliesTurn`'s class policy gains a third branch checked before the Magic User cast check — an opener-type ability in round 1, a damage ability when the target is above half hp, a defensive one when the member is below half — resolved through the same primitives the hero's `useAbility` uses (`memberStrike` with the descriptor, the shared foe-flag appliers, timers on the member's own sheet), with per-member `tickRounds`/`clearRoundTimers` call sites beside the hero's (post-research ruling: Joiner cooldowns clear at `endCombat`).

Purpose: SC-5 — a Joiner fights by class with its own tricks, and the "20 abilities × 2" surface stays one implementation, not two.
Output: `combat.js` member policy + resolution + tick sites, `derived.js` party Battle Roar term, four member events narrated, `test/unit/party-abilities.test.js`, ledger section.

Pure.
- `resolveMemberAbility(state, ally, sheet, view, meta, t, rng, events)`: push `memberAbilityUsed { name: ally.name, key: meta.id, ability: meta.name, ...(meta.target === "foe" ? { target: t.name } : {}) }`; start the timer on `sheet` with the same DURATION_ROUNDS/ONCE_A_FIGHT mapping as `useAbility` (import `ONCE_A_FIGHT`; keep a local `MEMBER_DURATION_ROUNDS` identical to abilities.js's or export `DURATION_ROUNDS` from abilities.js and import it — prefer the export); then by `meta.id`: strike kinds -> `memberStrike(state, ally, sheet, view, t, rng, events, descriptor)` (lastStand: loop up to 3 while `t.alive`); pommelStrike/dirtyTrick/poisonedEdge/hamstring/mark -> the shared appliers + the same Plan 03 event with `member: ally.name` added; cutpurse -> `rng.d(10) * ally.lvl` via `gainWilmst(state, amount, "cutpurse", rng, events)` + `cutpursed { target, amount, member }`; secondWind -> `ally.wp = Math.min(ally.maxWP, ally.wp + rng.d(8) + ally.lvl)` + `memberSecondWind { name, amount }`; sweep -> `memberSwept { name, dmg, count }` + per-foe `damageFoe(kind "ally")` + `sweptFoe`; brace -> `ally.braced = true` + `braced { member }`; riposte/taunt/sidestep/battleRoar/smoke -> the timer + the Plan 03 activation event with `member`.
- `memberStrike(..., mod = null)`: with `mod`: `attacks` ignored (the loop is the caller's), `need` shifted by `needShift` (floor 1), `autoHit` skips the miss branch, `bonusDmg` added after weaponDamage, `forceCrit` sets crit (subject to the existing member `noCrit` Guard/Soldier rule; silentStep denied by the heavy list), `finishUnder` kills a foe under the threshold (event `deathTouch { target, via, member }`), `dmgMul` after the crit doubling, `t.marked` +2 as the hero's; `allyStruck`/`allyMissed` gain `via: mod.key`. Without `mod` the function is byte-identical to today.
- foeTurn member branch: after the `C.parleyInsulted` step, `const mSheet = state.party[member.partyIdx]; if (mSheet && abilityEffectActive(mSheet, "sidestep")) { mNeed -= 2 (floor 1); mNeedMods.push({ name: "Sidestep", delta }) } if (mSheet && abilityEffectActive(mSheet, "smoke")) { mNeed = 1; push { name: "Smoke", delta } }`; on a miss: `if (mSheet && abilityEffectActive(mSheet, "riposte"))` counter with `weaponDamage(memberView(mSheet, member), rng)` through `damageFoe(kind "ally")` + `memberRiposted { name: member.name, target: f.name, dmg }` (+ killFoe/break on lethal); on a hit, before `member.wp -= mDmg`: `if (member.braced) { const before = mDmg; mDmg = Math.ceil(mDmg / 2); member.braced = false; events.push({ type: "braceHeld", name: f.name, member: member.name, soaked: before - mDmg }); }`.
- pickFoeTarget: after the hero taunt check, `const taunter = liveMembers.find((m) => { const s = state.party?.[m.partyIdx]; return s && abilityEffectActive(s, "taunt"); }); if (taunter) return taunter;` (before the die).
- foeTurn tail: directly after `if (c.timers) tickRounds(c);` add `for (const ally of C.allies || []) { if (ally.wp <= 0) continue; const s = Array.isArray(state.party) ? state.party[ally.partyIdx] : null; if (s && s.timers) tickRounds(s); }`. endCombat: inside the existing `C && C.allies` block, per surviving ally `if (sheet.timers) clearRoundTimers(sheet)`.
- derived.js: `export function partyEffectActive(state, key)` — `Array.isArray(state.party) && state.combat && Array.isArray(state.combat.allies) && state.combat.allies.some((a) => a.wp > 0 && abilityEffectActive(state.party[a.partyIdx], key))`; the Battle Roar term in both twins becomes `abilityEffectActive(c, "battleRoar") || partyEffectActive(state, "battleRoar")`.
