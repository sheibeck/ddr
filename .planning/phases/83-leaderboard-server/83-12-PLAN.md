<objective>
Bring the player's runs from the current release onto the new board, and nothing older.

User ruling (2026-09-28), which replaces the earlier "no backfill" ruling the same day: "Actually, any runs from the current version that we released just today, should show up on the new leaderboard, but nothing prior to that." The released version is 2.1.0 (versionCode 11, tag `v2.1.0-play11`, 2026-09-28 15:41:01 -0400 = 19:41:01 UTC).

Local run records carry no app version, only `when` (the death time in ms, `engineAdapter.js` passes `currentState.deathAt`). So the cutoff is a timestamp: a run counts when `when >= BACKFILL_SINCE_MS`. This is the original 83-06 Task 3 with that cutoff added and the version stamped as the real build instead of the literal "backfill".

Output: `src/browser/runBackfill.js` and `test/unit/runBackfill.test.js`. Phase 85 calls `runBackfill` at boot when Compete is ON; Phase 84's YOUR DEAD history imports local runs with the same `BACKFILL_SINCE_MS` cutoff (it imports the constant from this module).
</objective>
