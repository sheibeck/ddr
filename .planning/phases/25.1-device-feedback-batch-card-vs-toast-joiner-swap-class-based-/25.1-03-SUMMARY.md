# Phase 25.1 Plan 03: Joiners Fight By Class Summary

**Party members now fight according to their class — a Fighter swings its real weapon on the class/race to-hit and crits on a 1, a Thief opens the fight with a one-time backstab, and a Magic User casts its best castable attack spell (`bestAttackSpell`) on its own daily charges via a self-contained `allyCast` in `engine/combat.js` before falling back to a staff swing — with every new dice draw still behind the pre-existing `C.allies` gate, so solo parity stays byte-identical.**

## Accomplishments

- `engine/derived.js`: two new pure exports — `memberToHit(m)` (the class/race/sub part of to-hit for a party member sheet, not the hero) and `bestAttackSpell(state)` (the highest-effective-level castable attack spell from `castableAttackSpells`, preferring `kind === "thrown"` at an equal level).

A sheetless/unrecognized `C.allies` entry takes the byte-identical pre-25.1 legacy strike. ## Event Shapes (as committed)

- `allyCast { name, spell, target, roll?, need?, bonus? }` — Oracle-only; `roll`/`need`/`bonus` present only for a thrown cast (Freeze/Ice/Fireball(s)/Lightning), absent for status/stun/weaken.
- `allySpellHit { name, spell, target, effect: "damage"|"frozen"|"asleep"|"weakened", dmg?, rounds? }` — exactly one follows every `allyCast` that connects.
- `allySpellMissed { name, spell, target, resisted, roll? }` — `roll` present only on a resisted non-thrown cast.
- `allyStruck { name, target, dmg, weapon?, crit?, backstab? }` — the three new keys are conditionally spread; a legacy/summoned-ally payload has none of them.
- `allyMissed { name, target?, roll?, need?, weapon? }` — the classed path adds `target`/`roll`/`need`(+`weapon` if carried); the legacy/summoned-ally path stays `{ type, name }` only.

## memberToHit table

| Input | Result | Why |
|---|---|---|
| Fighter/Human | 5 | `CLASSES.Fighter.toHit` |
| Magic User/Human | 3 | `CLASSES["Magic User"].toHit` |
| Thief/Human | 4 | `CLASSES.Thief.toHit` |
| Thief/Elven | 5 | race `toHit` floor (5) beats class base (4) |
| Magic User/Human, sub Cleric | 4 | Cleric floor beats class base (3) |
| Thief/Human, sub Acrobat | 5 | Acrobat override (fixed 5, not a floor) |
| no recognized `cls` | 5 | `CLASSES[cls]?.toHit ?? 5` fallback |

## bestAttackSpell tie rule

Iterates `castableAttackSpells(state)` (already in `SPELLS` array order); keeps a candidate only on a **strict** improvement — a higher `spellLevelFor(sub, sp)` effective level, or the same level with `kind === "thrown"` over a non-thrown incumbent. Any remaining tie is broken implicitly by SPELLS order (the first candidate found is never displaced by an equal-or-worse later one). No charge check — that stays at `alliesTurn`'s call site (`maxCharges(view) - view.spellsUsed > 0`).

5. After a day passes (100 squares or a camp), a Magic User Joiner's spell charges are available again the next fight.
