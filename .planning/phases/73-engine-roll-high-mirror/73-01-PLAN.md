<interfaces>
engine/dice.js today (34 lines) exports `rollDice(rng, { n, sides, bonus })` (its loop draws `rng.d(sides)` n times) and `isBestFace(roll, dieN)` (returns `roll === 1`; leave it unchanged here, 73-05 flips it).

The helper contract this plan adds (names and shapes are fixed for every later plan):
- `rollCheck(rng, dieN, atLeast)`: draws exactly ONE `rng.d(dieN)` = r, computes `roll = dieN + 1 - r`, and returns a plain object `{ roll, atLeast, dieN, ok: roll >= atLeast }`. No clamping, no other draw.
- `atLeastFor(faces, dieN)`: returns `dieN + 1 - faces`. `faces` is a count of winning faces exactly as content and derived functions express it today (class toHit 3/4/5, weapon need mods, AR, sp.toHit, lock tiers, nimble, parley faces, `intel - 1` for resistance...). It may be 0 (never wins), negative, or above dieN (always wins).
- `rollFields(chk)`: returns exactly `{ roll: chk.roll, atLeast: chk.atLeast, dieN: chk.dieN }`, the triple every roll-carrying event spreads. `ok` never goes onto an event.

The mirror theorem the helper must satisfy: for any integer faces and any draw r in 1..N, `(r <= faces) === rollCheck(stub returning r, N, atLeastFor(faces, N)).ok`.

Tag grammar (the guard reads it): a trailing line comment `// roll:<kind>` on the SAME line as the raw draw, where kind is one of `amount` (damage, heal, duration, count, stat), `selection` (a table, kind, target or tier pick, including every comparison line of a selection ladder), `mishap-on-1` (a gate that fires a bad outcome on a natural 1 and stays there), `already-high` (a check whose winning faces already sit at the top). `primitive` is reserved for the two draws inside engine/dice.js. One tag covers every draw on its line. `rollDice(...)` calls need no tag (the amount primitive is tagged once, inside dice.js).

The roll-under shapes the scan forbids (validated against today's engine: every current check comparison matches one, and no non-check line in an enforced file does, once the selection lines above are tagged):
A "roll identifier" below is `roll` itself or a camelCase name ending in `Roll` (mRoll, firstRoll), optionally behind member access (chk.roll, e.roll): the core `(?:roll|\w*Roll)\b`. That core deliberately does NOT match `scroll`/`scrolls`, `Troll`, `rolls`, `rolled` or `rollDice`, which appear in engine code for other reasons.
- S1 a roll identifier left of `<`/`<=`: `/\b(?:\w+\.)*(?:roll|\w*Roll)\b\s*<=?(?![<=])/`
- S2 a roll identifier right of `>`/`>=`, never an arrow: `/(?<![=>\-])>=?\s*(?:\w+\.)*(?:roll|\w*Roll)\b(?!\s*\()/`
- S3 a raw draw left of `<`/`<=`: `/\.d\([^)]*\)\s*<=?(?![<=])/`
- S4 a raw draw right of `>`/`>=`: `/(?<![=>\-])>=?\s*[\w.]*\.d\(/`
- S5 short roll locals at or under: `/\b(?:r|dodge|soak|mRoll)\s*<=/` (note: `<=` only, so a loop `r < row.length` never fires)
- S6 threshold words on the roll-under side: `/(?:<=|(?<![=>\-])>)\s*(?:need|mNeed|faces|nimble|wakeOn)\b/`
- S7 a roll minus a bonus compared under: `/\b(?:\w+\.)*(?:roll|\w*Roll)\b\s*-\s*[\w.]+\s*<=?/`
- S8 keep-the-lower on a roll (never a `rollDice(` call, which encounters.js L644 and movement.js L395 clamp legitimately): `/Math\.min\(\s*(?:\w+\.)*(?:roll|\w*Roll)\b(?!\s*\()/`
Mirror arithmetic outside dice.js (M1): `/\+\s*1\s*-\s*(?:\w+\.)*(?:roll|\w*Roll)\b/`, `/\+\s*1\s*-\s*[\w.]*\.d\(/` and `/\b(?:dieN|sides|mDieN|legacyDieN)\s*\+\s*1\s*-/`.
Allowed roll-high shapes (must NOT fire): `if (chk.ok)`, `roll >= atLeast`, `atLeast <= roll`, `Math.max(chk.roll, second.roll)`, `rng.d(6) >= 4`, `rng.d(20) > 2`, `rng.d(8) === 1`, `(sp) => sp.roll !== "derived"` (character.js L319, an arrow plus a content field), `Math.min(rollDice(rng, a.loss), Math.max(0, c.wp - 1))` (an amount clamp), `for (let r = 0; r < row.length; r++)` (difficulty.js L820), `if (c.scrolls < 1)`, `if (x > c.scroll)` and `if (rolls.length > 2)` (not roll identifiers).
