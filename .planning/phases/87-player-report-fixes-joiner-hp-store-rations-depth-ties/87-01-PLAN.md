- startCombat builds `state.combat.allies` ONLY when `state.party.length` is truthy: each entry `{ partyIdx, name, lvl, sub, wp, maxWP }` (maxWP = sheet.maxWP ?? sheet.wp). A solo fight has no `allies` key at all.
- foeTurn member branch: `member.wp -= mDmg`, emits `memberStruck { name, member, dmg, ... }`, calls `downMember` when `member.wp <= 0`.
- downMember(state, member, events): sets `member.wp = 0`, SPLICES the entry out of `C.allies`, sets `state.party[member.partyIdx].status = "downed"`, emits `memberDowned`.
- Ally heals (~L2281: `ally.wp = Math.min(ally.maxWP, ally.wp + heal)`) and foe ability damage (engine/foeAbilities.js ~L286: `member.wp -= dmg`) also act on the roster entry.
- endCombat copies each roster `wp` back to `state.party[partyIdx].wp`, then drops `status: "downed"` members, then `state.combat = null`.
