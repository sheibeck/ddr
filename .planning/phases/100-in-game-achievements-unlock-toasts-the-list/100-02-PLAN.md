- `formatEarnedDate(at, tzOffsetMinutes)`: "D Mon YYYY" with no leading zero on the day, computed from `at - tzOffsetMinutes * 60000` read with UTC getters (tzOffsetMinutes is what `Date.prototype.getTimezoneOffset()` returns; a non-finite offset reads as 0). - `progressText(record, entry)`: null for a standard entry or an unknown entry; otherwise the string from `progressFor(record, entry)` using the bank: a `singleRunBest` depth entry uses `bestFloor`; the other `singleRunBest` entries (days, wilmstHeld) use `best` with their unit; `lifetimeCounter` uses `count` with the unit of its counter (kills for counter "kills"); `distinctSetCount` uses `count` with subClasses.

- `buildAchievementsView(record, opts)`: opts is `{ tzOffset }` (minutes, default 0). The record goes through `sanitizeRecord` (null or undefined through `emptyRecord()`); a throw while sanitising falls back to `emptyRecord()`. Returns a deeply frozen view:

  - `key` is the opaque string "t" plus the first entry's listOrder (never an id).
  - Track rows: `name` is the first rung's name without its trailing Roman numeral; `iconSrc` the highest earned rung's icon, or tier I's with `dim` true when none; `state` earned when every rung is earned, partial when some, locked when none; `detail` the highest earned rung's line, or tier I's description when none; `dateText` the highest earned rung's date text (or null); `progressText` the next unearned rung's progress (null when complete); `stateText` partial/complete/locked wording; `ladder` four `{ tier: numeral, state: "earned" or "locked" }`; `rungs` four `{ key, tier, name, state, text (the line when earned, the description when locked), dateText, progressText, iconSrc }`; `expandable` true.
  - Single rows: earned (line, dateText), locked (description, progressText for an incremental entry such as Tourist), secret (name = bank secret.name, detail = bank secret.line, silhouette true, iconSrc the entry's own icon, no date, no progress, no id word anywhere); `ladder` and `rungs` empty, `expandable` false.
  - `label` is one reading string: name, then stateText, then detail, then progressText, joined with ". ".
- `renderAchievementsSheet(host, view, opts)`: opts is `{ expanded, onToggle }` (`expanded` an array or Set of row keys; `onToggle` called with the key). Builds, through `host.ownerDocument` only, and replaces the host's children with, one root `div.mw-ach` holding: `div.mw-ach-summary` (two `p`: `.mw-ach-count`, `.mw-ach-secrets`); per block a `section.mw-ach-block` with `h3.mw-ach-block-title` and `ul.mw-ach-list`; per row an `li.mw-ach-row` carrying data-state, data-kind and data-key; inside it the head (a `button.mw-ach-head` with type "button" and aria-expanded for a track, a `div.mw-ach-head` otherwise) holding `img.mw-ach-icon` (alt "", aria-hidden "true", plus class mw-ach-icon-dim for a dim row and mw-ach-icon-silhouette for a silhouette) and `div.mw-ach-text` with `span.mw-ach-name`, `span.mw-ach-state`, `span.mw-ach-detail`, `span.mw-ach-progress` (in that DOM order; empty parts omitted), plus for a track `span.mw-ach-ladder` (aria-hidden, four `i` pips with data-state and the numeral as text); an expanded track also gets, directly after its head inside the same `li`, a `ul.mw-ach-rungs` of four `li.mw-ach-rung` (name, state or date, text, progress).
