<interfaces>
- `engine/records.js`: `export function reconcileBests(record, graves)`. It returns a sanitized BestsRecord:
  - start from `sanitizeBests(record)` and remember its `last`;
  - when `graves` is an array, walk it oldest first (it is stored newest first, so a reversed copy);
  - `normalizeStone` each entry and skip the null ones;
  - skip a stone whose hash the record's `runs` already holds;
  - otherwise fold it with `updateBests(rec, stone).record`;
  - finally set `last` back to the remembered value and return.
  A non-array `graves` returns `sanitizeBests(record)`. It never throws: a caught failure returns `sanitizeBests(record)`.
- `src/browser/engineAdapter.js#loadBests()`:
  - after `bests` is set (parsed, or backfilled), read GRAVE_KEY once, parse it tolerantly (a non-array means []) and set `bests = reconcileBests(bests, graves)`;
  - when `JSON.stringify` of the result differs from before, enqueue `track(storage.setItem(BESTS_KEY, JSON.stringify(bests)))`;
  - never touch `deathRecord`, `runRecordedListener` or the graveyard keys;
  - the backfill path may skip the extra read, since backfill already folded every stone.
</interfaces>
