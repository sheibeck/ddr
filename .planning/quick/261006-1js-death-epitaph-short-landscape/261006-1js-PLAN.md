# Quick 261006-1js: The death screen keeps its epitaph in short landscape windows

## Bug
User ruling, 2026-10-06: fix it now, before the 2.5.0 screenshots.

The Phase 102 capture found the bug. In a 960 × 540 CSS window (a 7" tablet in landscape, layout class `expanded`), the death panel (`#cb-over`, built by `renderCombatOver`'s dead branch in `mazeworld.html`) squeezes its middle block `.cb-mid` to zero height. The epitaph is lost: "<name>, <race> <sub>, cut down by …", "Floor N · day N · XP", "Cause of death: …".

What happens instead: the EARNED, POSTHUMOUSLY strip (`.cb-over-earned`, Phase 100), the Special Snowflake hint (`#cb-over-hint`, quick 261005-vn5) and the three buttons (REVIEW THE ORACLE, FINAL SHEET, BURY THEM) take all the room. Phones and the 10" tablet are fine.

## Fix
- Make the epitaph block never collapse. The death panel content (epitaph, Earned strip, hint, buttons) should flow in one column that scrolls as a whole when it doesn't fit. Give `.cb-mid` its natural height; don't let flex shrink it to 0.
- Avoid nested scrollers that layout-check rejects, and keep both death buttons reachable by scrolling. In short windows, the Earned strip may cap its own height (it already scrolls inside itself, at most 9.5em).
- Read first:
  - the Phase 100 and 261005-vn5 SUMMARIES (`.planning/phases/100-in-game-achievements-unlock-toasts-the-list/100-04-SUMMARY.md`, `.planning/quick/261005-vn5-special-snowflake-secret/261005-vn5-SUMMARY.md`);
  - the death panel CSS in `mazeworld.html`;
  - the layout-check `death-earned` scene in `tools/layout-check.mjs`.
- Extend `tools/layout-check.mjs`'s death scene to assert that the epitaph block has a positive height and its "Cause of death" line is in the scrolled content, in every profile, including 960 × 540 and the short landscape phone profiles. Run `LAYOUT_CHECK_BOOT_MS=240000 npm run layout:check`; this machine's cold boot is slow.
- Run the targeted shell tests for the death panel: banner-shell, the death and final-sheet suites, layout-shell, shell-tab-snapshots, reduced-motion and text-scale. Any snapshot that moves is declared.
