## Deviations from Plan

**1. [Rule 1 - layout] The hint is not a nested scroller.** The plan said it should scroll inside itself like the strip. A scroller below the fold in the short landscape profiles trips layout-check's generic out-of-window rule, and a nested scroller on a two-line hint is a touch trap. The death panel already scrolls as a whole, so the buttons stay reachable; the line wraps and grows with the text scale. Tests and layout-check assert "not a scroller, not clipped".

**2. Fifteenth catalog field on every entry** rather than an optional key on one entry, to keep "every entry carries the same fields" (the catalog test and the header comment pin it). 77 one-line additions.

**3. layout-check scene data.** Special Snowflake can no longer sit in the six-item Earned strip of the `death-earned` scene (it is the reveal being tested), so Unicorn! takes its place; the 6-item pin is unchanged.

No engine, adapter or Play-mirror file changed. No fixtures moved.
