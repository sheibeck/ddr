# v2.3 item audit findings (for Phase 89)

Findings from the 2026-09-30 rules ledger (https://claude.ai/artifact/L5dSqR5egZZJV6dvdJEuma) and from Phase 87–88 work. The user asked (2026-09-30) that the Phase 89 item audit (ITEM-01 / ITEM-06) pick these up: each gets a fix or a recorded ruling, pinned by a test.

Required reading for the Phase 89 discuss and every Phase 89 plan.

## Text and engine disagree

- **Poplar Staff.** Text: "1d20+10 hp to up to 6". Engine: the staff's `use: "heal"` resolves to `useItem`'s `case "heal"` (`engine/items.js`, the Healing potion's branch), so it heals d10+2 to the hero only. `useItem` picks `kind = it.use ?? activationFor(it)?.kind` (~L1432).
- **Walnut Staff.** Text: "all hits on the weakened do double damage". Engine: `use: "weaken"` runs the Weaken effect (`combat.weakened`, read by `derived.js#foeWeakened`), which halves the foes' damage. Halving their damage is not doubling yours.
- **Death potion.** Text typo: "your dead!" should read "you're dead!" (`content/potions.js`).

## A benefit that can outlive its item

- **Pendant of Fortitude.** `use: "half"` sets `c.halfNext = true` on the character, not on the pendant, so the armed half-damage flag likely survives taking the pendant off. It is not a timed record, so Phase 88's source link (ITEM-02) does not cover it. Recorded by the Phase 88 planner too.

## Joiners (ITEM-06 candidates)

- **Joiners can't use items.** Only the hero's `useItem` → `applyActivation(state.c)` starts an item effect; Joiner sheets hold rolled gear with no path that uses it (Phase 88 scout). Phase 88 builds the source link for any sheet, so Joiner item use would be covered once it exists.
- **Joiner armour never soaks a foe hit.** The member branch of `foeTurn` subtracts the full damage (finding from Phase 87, plan 87-01).
