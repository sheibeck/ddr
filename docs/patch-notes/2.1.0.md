# Delve, Die, Repeat 2.1.0

## Headline
Version 2.1.0. The full notes land before this build goes out; these are the first lines.
- The ☰ menu gains PATCH NOTES and REPORT A BUG.

## Interface
- ☰ menu: nowhere to read what changed → a PATCH NOTES row shows this version's notes, even offline, and opens once by itself after an update.
- ☰ menu: nowhere to report a bug → a REPORT A BUG row sends what you type and this run's Oracle to the developer, posted publicly on GitHub.
